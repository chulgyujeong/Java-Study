## 1. 메소드(Method)

[↑ 목차로 돌아가기](#top)

### 1.1 메소드의 개념

메소드는 특정 작업을 수행하기 위한 명령문의 집합이다.

- 코드 재사용
- 기능 분리
- 중복 코드 감소
- 유지보수 편의성 향상

```java
static 반환형 메소드명(매개변수) {
    // 실행할 명령문
    return 결과값;
}
```

| 구성 요소 | 의미 |
|---|---|
| `static` | 객체 생성 없이 클래스 이름으로 호출 가능 |
| 반환형 | 메소드가 반환하는 값의 자료형 |
| 메소드명 | 메소드의 이름 |
| 매개변수 | 외부에서 전달받는 값 |
| `return` | 결과를 반환하고 메소드를 종료 |

### 1.2 배열을 이용한 합계·최소값·최대값·평균

```java
import java.util.*;

public class Method1 {

    static int hap(int[] arr) {
        int sum = 0;

        for (int i : arr) {
            sum += i;
        }

        return sum;
    }

    static int min(int[] arr) {
        int min = arr[0];

        for (int i : arr) {
            if (i < min) {
                min = i;
            }
        }

        return min;
    }

    static int max(int[] arr) {
        int max = arr[0];

        for (int i : arr) {
            if (i > max) {
                max = i;
            }
        }

        return max;
    }

    static double avg(int[] arr) {
        return (double) hap(arr) / arr.length;
    }

    public static void main(String[] args) {
        int[] arr = new int[10];

        for (int i = 0; i < arr.length; i++) {
            arr[i] = (int) (Math.random() * 100) + 1;
        }

        System.out.println(Arrays.toString(arr));
        System.out.println("합계: " + hap(arr));
        System.out.println("최소값: " + min(arr));
        System.out.println("최대값: " + max(arr));
        System.out.println("평균: " + avg(arr));
    }
}
```

**핵심 개념**

- `int[]`: 정수 배열
- `for (int i : arr)`: 배열의 원소를 순서대로 조회
- `Math.random()`: 난수 생성
- `(double)`: 실수형으로 변환
- `arr.length`: 배열의 길이

### 1.3 짝수와 홀수 개수 구하기

```java
static int even(int[] arr) {
    int count = 0;

    for (int i : arr) {
        if (i % 2 == 0) {
            count++;
        }
    }

    return count;
}

static int odd(int[] arr) {
    int count = 0;

    for (int i : arr) {
        if (i % 2 != 0) {
            count++;
        }
    }

    return count;
}
```

| 표현 | 의미 |
|---|---|
| `i % 2 == 0` | 짝수 |
| `i % 2 != 0` | 홀수 |
| `count++` | 개수 1 증가 |

### 1.4 문자열 배열 검색

```java
import java.util.*;

public class Method2 {

    static String[] nameFind(String name) {
        String[] names = {
            "홍길동", "이순신", "강감찬", "심청이", "춘향이"
        };

        int count = 0;

        for (String n : names) {
            if (n.contains(name)) {
                count++;
            }
        }

        String[] result = new String[count];
        int index = 0;

        for (String n : names) {
            if (n.contains(name)) {
                result[index++] = n;
            }
        }

        return result;
    }

    public static void main(String[] args) {
        System.out.println(Arrays.toString(nameFind("홍길동")));
        System.out.println(Arrays.toString(nameFind("이")));
    }
}
```

**핵심 개념**

- `contains()`: 문자열에 특정 문자열이 포함되어 있는지 검사
- 검색 결과의 개수를 먼저 계산한 후 결과 배열 생성
- 검색 결과가 없으면 길이가 0인 배열 반환

### 1.5 boolean을 이용한 로그인 처리

```java
import java.util.*;

public class Method3 {

    static boolean isLogin(String id, String pwd) {
        return id.equals("admin") && pwd.equals("1234");
    }

    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);

        System.out.print("ID, Password 입력: ");

        String id = scan.next();
        String pwd = scan.next();

        if (isLogin(id, pwd)) {
            System.out.println("로그인되었습니다.");
        } else {
            System.out.println("로그인 실패하였습니다.");
        }

        scan.close();
    }
}
```

**핵심 개념**

- `boolean`: `true` 또는 `false`
- `equals()`: 문자열 내용 비교
- `&&`: 두 조건이 모두 참이면 참
- `return`: 결과를 반환하고 메소드 종료

## 2. 클래스와 객체

[↑ 목차로 돌아가기](#top)

### 2.1 클래스의 개념

클래스는 객체를 생성하기 위한 설계도다.

```java
class Student {
    String name;
    int hakbun;
    String sex;
}
```

```java
Student hong = new Student();
```

- `Student`: 클래스이자 사용자 정의 자료형
- `hong`: 객체를 참조하는 변수
- `new Student()`: 새로운 객체 생성

### 2.2 클래스의 종류

| 종류 | 역할 | 대표적인 이름 |
|---|---|---|
| 데이터 중심 | 데이터 관리 | `VO`, `DTO` |
| 기능 중심 | 업무 기능 처리 | `Service`, `Manager` |
| 혼합형 | 데이터와 기능을 함께 관리 | 일반 클래스 |

이는 실무에서 자주 사용하는 분류 방식이며 절대적인 규칙은 아니다.

### 2.3 인스턴스 변수와 정적 변수

```java
class Card {
    int no;
    String type;

    static int width;
    static int height;
}
```

| 구분 | 인스턴스 변수 | 정적 변수 |
|---|---|---|
| 소속 | 객체 | 클래스 |
| 저장 특성 | 객체마다 별도 값 | 클래스 차원에서 공유 |
| 접근 권장 방식 | `객체.변수` | `클래스명.변수` |

### 2.4 클래스 필드의 기본 초기값

| 자료형 | 기본 초기값 |
|---|---|
| `int`, `long`, `short`, `byte` | `0` |
| `float` | `0.0f` |
| `double` | `0.0` |
| `char` | `'\u0000'` |
| `boolean` | `false` |
| 참조형 | `null` |

※ 기본 초기값은 클래스의 필드에 적용된다. 지역변수는 사용하기 전에 초기화해야 한다.

## 3. 생성자(Constructor)

[↑ 목차로 돌아가기](#top)

### 3.1 생성자의 개념

생성자는 객체가 생성될 때 초기화 작업을 수행하는 특별한 구성 요소다.

- 클래스 이름과 생성자 이름이 같다.
- 반환형을 작성하지 않는다.
- `new`를 통한 객체 생성 과정에서 호출된다.
- 매개변수로 외부 데이터를 전달받을 수 있다.

| 구분 | 생성자 | 일반 메소드 |
|---|---|---|
| 이름 | 클래스 이름과 동일 | 자유롭게 지정 |
| 반환형 | 없음 | 반환형 지정 |
| 목적 | 객체 초기화 | 기능 수행 |

### 3.2 생성자를 이용한 Student 클래스

```java
class Student {
    String name;
    int hakbun;
    String sex;

    Student(String n, int h, String s) {
        name = n;
        hakbun = h;
        sex = s;
    }
}
```

### 3.3 생성자를 이용한 객체 생성

```java
public class Class1 {

    public static void main(String[] args) {
        Student hong = new Student("홍길동", 1, "남자");
        Student shim = new Student("심청이", 2, "여자");
        Student park = new Student("박문수", 3, "남자");

        System.out.println(hong.name);
        System.out.println(shim.name);
        System.out.println(park.name);
    }
}
```

**객체 생성 과정**

1. `new Student(...)`로 객체 생성
2. 전달한 값을 생성자의 매개변수로 받음
3. 인스턴스 변수에 값 저장
4. 참조변수로 객체에 접근

## 4. 클래스 활용 예제

[↑ 목차로 돌아가기](#top)

### 4.1 Movie 클래스

영화 한 편의 데이터를 관리하는 클래스다.

```java
public class Movie {
    int mno;
    String title;
    String genre;
    String poster;
    String actor;
    String regdate;
    String grade;
    String director;
}
```

```java
Movie movie = new Movie();

movie.mno = 1;
movie.title = "쇼생크 탈출";
movie.genre = "드라마";
movie.director = "프랭크 다라본트";
```

### 4.2 MovieSystem 클래스

```java
public class MovieSystem {

    static Movie[] movies = new Movie[1938];

    static {
        try {
            // 클래스 초기화 작업
        } catch (Exception ex) {
            ex.printStackTrace();
        }
    }
}
```

- `Movie[]`: Movie 객체를 참조하는 배열
- `new Movie[1938]`: 참조 공간 1938개 생성
- `static {}`: 클래스 초기화 블록

주의: 배열을 생성했다고 해서 Movie 객체 1938개가 자동으로 생성되는 것은 아니다. 각 요소는 객체를 할당하기 전까지 `null`이다.

```java
movies[0] = new Movie();
movies[0].title = "쇼생크 탈출";
```

### 4.3 Card 클래스와 static 변수

```java
class Card {
    int no;
    String type;

    static int width;
    static int height;
}
```

```java
public class UserMain {

    public static void main(String[] args) {
        Card a = new Card();
        a.no = 2;
        a.type = "☆";

        Card b = new Card();
        b.no = 3;
        b.type = "◆";

        Card.width = 200;
        Card.height = 300;

        System.out.println(a.no);
        System.out.println(a.type);
        System.out.println(Card.width);
        System.out.println(Card.height);
    }
}
```

`static` 변수는 모든 인스턴스가 공유한다.

```java
Card.width = 200;
Card.width = 250;
Card.width = 270;

System.out.println(Card.width); // 270
```

각 객체마다 서로 다른 너비와 높이가 필요하다면 `static`을 제거한다.

## 5. 핵심 개념 요약
