## 1. 인터페이스(Interface)

### 1-1. 인터페이스란?

인터페이스는 서로 다른 클래스들이 공통으로 따라야 할 기능의 규격을 정의하는 역할을 한다.

- 서로 다른 클래스를 하나의 인터페이스 이름으로 관리할 수 있다.
- 구현 클래스가 동일한 메소드 형식을 사용하도록 표준화할 수 있다.
- 구현체와 사용하는 코드 사이의 결합도를 낮출 수 있다.
- 클래스는 여러 인터페이스를 구현할 수 있다.

예를 들어 게시판, 회원가입, 로그인, 맛집 목록, 맛집 상세보기는 서로 다른 기능이지만 `Execute`라는 인터페이스를 구현하면 동일한 방식으로 실행할 수 있다.

### 1-2. 인터페이스의 기본 구성

```java
public interface HelloInter {

    // 추상 메소드
    public void sayHello(String name);

}
```

인터페이스를 구현하는 클래스는 `implements`를 사용한다.

```java
public class Hello implements HelloInter {

    @Override
    public void sayHello(String name) {
        System.out.println(name + "님 환영합니다!!");
    }
}
```

실행 클래스에서는 인터페이스 타입으로 객체를 참조할 수 있다.

```java
public class HelloMain {

    public static void main(String[] args) {

        HelloInter hello = new Hello();

        hello.sayHello("홍길동");
    }
}
```

**실행 결과**

```text
홍길동님 환영합니다!!
```

`HelloInter hello = new Hello();`

- 참조변수의 데이터형: `HelloInter`
- 실제 생성된 객체: `Hello`
- 인터페이스에 선언된 메소드만 참조변수를 통해 사용할 수 있다.
- 실제 실행되는 메소드는 객체의 오버라이딩된 구현 내용이다.

### 1-3. 인터페이스의 구성 요소

인터페이스에는 상수, 추상 메소드, default 메소드, static 메소드, private 메소드가 존재한다.

**① 상수(Constant)**

인터페이스에 선언하는 변수는 자동으로 `public static final`이 적용된다.

```java
public interface A {

    int MAX = 100;

}
```

위 코드는 다음과 같은 의미다.

```java
public static final int MAX = 100;
```

- 반드시 선언과 동시에 초기화해야 한다.
- 값을 변경할 수 없다.
- 인터페이스 이름으로 접근할 수 있다.

```java
System.out.println(A.MAX);
```

**② 추상 메소드(Abstract Method)**

구현 내용이 없는 메소드다.

```java
public interface A {

    void display();

}
```

다음과 같은 의미다.

```java
public abstract void display();
```

인터페이스의 일반적인 추상 메소드는 `public abstract`가 자동으로 적용된다. 이를 구현하는 클래스는 해당 메소드를 `public`으로 오버라이딩해야 한다.

**③ default 메소드**

인터페이스 내부에서 구현 내용을 제공하는 인스턴스 메소드다.

```java
public interface A {

    default void display() {
        System.out.println("기본 기능 실행");
    }

}
```

- 구현 클래스에서 반드시 오버라이딩할 필요는 없다.
- 기존 인터페이스를 구현하는 클래스에 새로운 기능을 추가할 때 활용할 수 있다.

**④ static 메소드**

인터페이스 자체에 속하는 메소드다.

```java
public interface A {

    static void print() {
        System.out.println("인터페이스 static 메소드");
    }

}
```

인터페이스 이름으로 호출한다.

```java
A.print();
```

**⑤ private 메소드**

인터페이스 내부에서만 사용할 수 있는 메소드다.

```java
public interface A {

    private void display() {
        System.out.println("내부 공통 기능");
    }

    default void run() {
        display();
    }
}
```

- Java 9부터 인터페이스의 private 메소드 사용이 가능하다.
- 인터페이스 내부의 default 메소드나 static 메소드 등에서 공통 로직을 재사용할 때 활용한다.
- 구현 클래스에서 직접 호출하거나 오버라이딩할 수 없다.

### 1-4. 인터페이스의 상속과 구현

| 관계 | 사용 문법 |
|---|---|
| 인터페이스 → 인터페이스 | `extends` |
| 클래스 → 인터페이스 | `implements` |
| 클래스 → 클래스 | `extends` |

**인터페이스끼리 상속**

```java
interface A {
    void displayA();
}

interface B extends A {
    void displayB();
}

interface C extends A, B {
    void displayC();
}
```

**클래스에서 여러 인터페이스 구현**

```java
interface A {
    void displayA();
}

interface B {
    void displayB();
}

class C implements A, B {

    @Override
    public void displayA() {
        System.out.println("A 기능");
    }

    @Override
    public void displayB() {
        System.out.println("B 기능");
    }
}
```

**클래스 상속과 인터페이스 구현을 함께 사용**

```java
class A {
    public void display() {
        System.out.println("A 기능");
    }
}

interface B {
    void print();
}

interface C {
    void show();
}

class D extends A implements B, C {

    @Override
    public void print() {
        System.out.println("B 기능");
    }

    @Override
    public void show() {
        System.out.println("C 기능");
    }
}
```

클래스는 여러 클래스를 동시에 상속할 수 없지만, 여러 인터페이스를 동시에 구현할 수 있다.

### 1-5. 인터페이스를 활용한 프로그램 구조

여러 기능을 하나의 인터페이스로 통일하면 조건문을 반복해서 작성하지 않고도 객체를 실행할 수 있다.

**실행 규격 정의**

```java
public interface Execute {
    void execute();
}
```

**각 기능별 클래스 구현**

```java
public class 게시판 implements Execute {

    @Override
    public void execute() {
        System.out.println("게시판 접속!!");
    }
}
```

```java
public class 로그인 implements Execute {

    @Override
    public void execute() {
        System.out.println("로그인 처리!!");
    }
}
```

```java
public class 회원가입 implements Execute {

    @Override
    public void execute() {
        System.out.println("회원가입 처리!!");
    }
}
```

**Map을 활용한 기능 관리**

```java
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

public class UserMain {

    public static void main(String[] args) {

        Scanner scan = new Scanner(System.in);

        System.out.println(
            "메뉴 선택: 게시판=1, 회원가입=2, 로그인=3"
        );

        int menu = scan.nextInt();

        Map<String, Execute> map = new HashMap<>();

        map.put("1", new 게시판());
        map.put("2", new 회원가입());
        map.put("3", new 로그인());

        Execute e = map.get(String.valueOf(menu));

        if (e != null) {
            e.execute();
        } else {
            System.out.println("잘못된 메뉴입니다.");
        }

        scan.close();
    }
}
```

**핵심 개념**

- `Map`: 키(Key)와 값(Value)을 함께 저장하는 자료구조
- `Execute`: 여러 클래스가 공통으로 구현하는 인터페이스
- `map.get()`: 메뉴 번호에 해당하는 객체를 가져온다.
- `e.execute()`: 실제 객체의 오버라이딩된 메소드가 실행된다.

이 방식은 새로운 기능을 추가하더라도 기존 메뉴 실행 구조를 크게 변경하지 않아도 된다는 장점이 있다.

### 1-6. 인터페이스의 활용 분야

- GUI 프로그램의 이벤트 처리
- 쓰레드 실행 규격
- 데이터베이스 연결 및 처리
- 네트워크 통신
- 웹 애플리케이션의 서비스 구조
- 프레임워크에서의 표준화된 기능 설계

## 2. 추상 클래스(Abstract Class)

### 2-1. 추상 클래스란?

추상 클래스는 공통적인 기능과 구조를 상위 클래스에 정의하고, 하위 클래스가 필요한 기능을 구체적으로 구현하도록 설계하는 클래스다.

```java
public abstract class ClassName {

    // 인스턴스 변수
    int a;

    // 생성자
    public ClassName() {
    }

    // 구현된 메소드
    public void display() {
        System.out.println("공통 기능");
    }

    // 추상 메소드
    public abstract void process();

}
```

추상 클래스는 `abstract` 키워드를 사용한다.

### 2-2. 추상 클래스의 특징

1. 추상 메소드를 포함할 수 있다.
2. 일반 변수와 static 변수 등을 선언할 수 있다.
3. 생성자를 가질 수 있다.
4. 구현된 메소드와 추상 메소드를 함께 사용할 수 있다.
5. 직접 객체를 생성할 수 없다.
6. 상속받은 하위 클래스에서 추상 메소드를 구현해야 한다. 단, 하위 클래스도 추상 클래스로 선언할 수 있다.

### 2-3. 추상 클래스 사용 예제

```java
abstract class Movie {

    public abstract void play();

    public void info() {
        System.out.println("영화관 정보");
    }
}
```

```java
class Megabox extends Movie {

    @Override
    public void play() {
        System.out.println("메가박스 상영");
    }
}
```

```java
class CGV extends Movie {

    @Override
    public void play() {
        System.out.println("CGV 상영");
    }
}
```

```java
public class MovieMain {

    public static void main(String[] args) {

        Movie m = new Megabox();
        m.play();

        m = new CGV();
        m.play();

    }
}
```

**실행 결과**

```text
메가박스 상영
CGV 상영
```

### 2-4. 추상 클래스의 목적

- 공통 기능을 상위 클래스에서 관리한다.
- 하위 클래스에서 구현해야 할 기능을 강제할 수 있다.
- 상속을 통해 코드 재사용성을 높인다.
- 새로운 하위 클래스를 추가하기 쉽다.
- 공통 구조를 유지하면서 각 클래스의 기능을 확장할 수 있다.

## 3. 다형성(Polymorphism)

### 3-1. 다형성이란?

다형성은 하나의 상위 타입으로 여러 종류의 객체를 참조하고, 실제 객체에 따라 서로 다른 기능을 실행할 수 있는 성질이다.

```java
class A {

    public void display() {
        System.out.println("A 실행");
    }
}

class B extends A {

    @Override
    public void display() {
        System.out.println("B 실행");
    }
}

class C extends A {

    @Override
    public void display() {
        System.out.println("C 실행");
    }
}
```

```java
public class Main {

    public static void main(String[] args) {

        A a = new B();
        a.display();

        a = new C();
        a.display();

    }
}
```

**실행 결과**

```text
B 실행
C 실행
```

참조변수의 타입은 `A`이지만 실제 객체는 `B`, `C`이므로 각각의 오버라이딩된 메소드가 실행된다.

### 3-2. 상위 클래스와 하위 클래스의 관계

```java
class A {
}

class B extends A {
}
```

다음은 가능하다.

```java
A a = new B();
```

상위 클래스 타입의 참조변수로 하위 클래스 객체를 참조할 수 있다.

반대로 다음은 일반적으로 불가능하다.

```java
B b = new A(); // 컴파일 오류
```

실제 객체가 `A`이므로 `B`에 정의된 기능을 보장할 수 없기 때문이다.

### 3-3. 업캐스팅과 다운캐스팅

**① 업캐스팅(Upcasting)**

하위 클래스 객체를 상위 클래스 타입으로 참조하는 것이다.

```java
A a = new B();
```

- 자동 형변환이 가능하다.
- 상위 클래스에서 선언한 기능을 사용할 수 있다.
- 오버라이딩된 메소드는 실제 객체의 구현 내용이 실행된다.

**② 다운캐스팅(Downcasting)**

상위 클래스 타입의 참조변수를 하위 클래스 타입으로 변환하는 것이다.

```java
A a = new B();

B b = (B) a;
```

- 명시적 형변환이 필요하다.
- 실제 객체가 변환하려는 하위 타입이어야 한다.
- 잘못된 형변환은 `ClassCastException`을 발생시킬 수 있다.

안전하게 형변환하려면 `instanceof`를 활용한다.

```java
if (a instanceof B) {
    B b = (B) a;
    System.out.println("B 객체로 변환 가능");
}
```

### 3-4. 오버라이딩(Overriding)

상속 관계에서 하위 클래스가 상위 클래스의 메소드를 재정의하는 것이다.

주요 조건은 다음과 같다.

1. 상속 관계가 있어야 한다.
2. 메소드 이름이 같아야 한다.
3. 매개변수 목록이 같아야 한다.
4. 반환 타입은 동일하거나 허용되는 범위에서 공변 반환 타입을 사용할 수 있다.
5. 접근 제한자는 상위 메소드보다 좁아질 수 없다.

```java
class Parent {

    public void display() {
        System.out.println("부모 클래스");
    }
}

class Child extends Parent {

    @Override
    public void display() {
        System.out.println("자식 클래스");
    }
}
```

`@Override`는 오버라이딩 의도를 명확하게 표시하고, 잘못된 메소드 선언을 컴파일 단계에서 확인하는 데 도움을 준다.

### 3-5. 다형성의 장점

- 여러 객체를 동일한 타입으로 관리할 수 있다.
- 조건문을 줄이고 코드 구조를 단순화할 수 있다.
- 새로운 클래스를 추가하기 쉽다.
- 객체 간 결합도를 낮출 수 있다.
- 유지보수와 확장에 유리하다.

## 4. Swing 이벤트 처리와 퍼즐 게임

### 4-1. Swing이란?

Swing은 Java에서 GUI(Graphical User Interface)를 구현하기 위한 라이브러리다.

```java
import java.awt.*;
import javax.swing.*;
import java.awt.event.*;
```

주요 구성 요소는 다음과 같다.

| 클래스 | 역할 |
|---|---|
| `JFrame` | 윈도우 창 |
| `JPanel` | 컴포넌트를 배치하는 패널 |
| `JButton` | 버튼 |
| `JLabel` | 문자열 또는 이미지 표시 |
| `JOptionPane` | 메시지 및 확인 창 |
| `GridLayout` | 격자 형태의 배치 |

### 4-2. 이벤트(Event)란?

사용자의 행동에 따라 프로그램에서 발생하는 사건이다.

예를 들어 다음과 같은 행동이 이벤트에 해당한다.

- 버튼 클릭
- 마우스 클릭
- 마우스 진입 및 이탈
- 키보드 입력
- 창 열기 및 닫기

이벤트가 발생하면 이벤트 리스너가 해당 동작을 처리한다.

### 4-3. 이벤트 리스너 인터페이스

대표적인 이벤트 리스너는 다음과 같다.

| 인터페이스 | 주요 메소드 |
|---|---|
| `ActionListener` | `actionPerformed()` |
| `MouseListener` | `mouseClicked()`, `mousePressed()`, `mouseReleased()`, `mouseEntered()`, `mouseExited()` |
| `WindowListener` | `windowOpened()`, `windowClosing()`, `windowClosed()` 등 |

인터페이스를 구현하면 해당 인터페이스의 추상 메소드를 구현해야 한다.

```java
public class EventTest implements ActionListener {

    @Override
    public void actionPerformed(ActionEvent e) {
        System.out.println("버튼 클릭");
    }
}
```

버튼에 이벤트 리스너를 등록한다.

```java
JButton btn = new JButton("확인");

btn.addActionListener(this);
```

### 4-4. ActionListener와 MouseListener 비교

**ActionListener**

버튼 클릭과 같은 액션 이벤트를 처리한다.

```java
@Override
public void actionPerformed(ActionEvent e) {

    if (e.getSource() == btn) {
        System.out.println("버튼 클릭");
    }
}
```

**MouseListener**

마우스의 클릭, 누름, 놓음, 진입, 이탈 등을 처리한다.

```java
@Override
public void mouseEntered(MouseEvent e) {

    if (e.getSource() == btn) {
        btn.setBackground(Color.GREEN);
    }
}

@Override
public void mouseExited(MouseEvent e) {

    if (e.getSource() == btn) {
        btn.setBackground(Color.WHITE);
    }
}
```

`getSource()`는 이벤트를 발생시킨 객체를 반환한다.

### 4-5. GridLayout

컴포넌트를 행과 열로 나누어 일정한 크기로 배치한다.

```java
JPanel pan = new JPanel();

pan.setLayout(new GridLayout(3, 3, 5, 5));
```

- 첫 번째 인자: 행(Row)
- 두 번째 인자: 열(Column)
- 세 번째 인자: 가로 간격
- 네 번째 인자: 세로 간격

3행 3열로 구성하면 총 9개의 영역을 만들 수 있다.

### 4-6. 퍼즐 게임의 기본 구조

수업에서 작성한 퍼즐 게임은 3×3 버튼을 사용하여 숫자 1~8과 빈칸을 배치하는 구조다.

**주요 변수**

```java
JButton[] btns = new JButton[9];

// 퍼즐의 숫자 상태 저장
int[] panCount = new int[9];

// 빈칸의 위치
int last = 0;
```

- `btns`: 화면에 표시되는 버튼 배열
- `panCount`: 퍼즐 내부의 숫자 배열
- `last`: 빈칸의 현재 위치
- 숫자 `8`: 빈칸을 나타내는 내부 값으로 사용

**버튼 생성**

```java
for (int i = 0; i < btns.length; i++) {

    btns[i] = new JButton(String.valueOf(i + 1));

    btns[i].setFont(
        new Font("궁서체", Font.BOLD, 45)
    );

    btns[i].addActionListener(this);
    btns[i].addMouseListener(this);

    pan.add(btns[i]);
}
```

**난수 생성**

```java
public void getRand() {

    for (int i = 0; i < 9; i++) {

        panCount[i] = (int)(Math.random() * 9);

        for (int j = 0; j < i; j++) {

            if (panCount[i] == panCount[j]) {
                i--;
                break;
            }
        }
    }

    for (int i = 0; i < 9; i++) {

        if (panCount[i] == 8) {
            last = i;
            break;
        }
    }
}
```

`Math.random()`은 0 이상 1 미만의 난수를 반환한다.

`(int)(Math.random() * 9)`를 사용하면 0~8 사이의 정수를 만들 수 있다.

위 코드는 중복 숫자를 검사하여 0~8이 한 번씩 들어가도록 구성한다.

**퍼즐 화면 갱신**

```java
public void puzzleLayout() {

    for (int i = 0; i < 9; i++) {

        if (last == i) {
            btns[i].setText("");
        } else {
            btns[i].setText(
                String.valueOf(panCount[i] + 1)
            );
        }
    }
}
```

내부 배열의 값이 8인 위치는 빈칸으로 표시하고, 나머지는 1을 더해 화면에 출력한다.

**퍼즐 종료 여부 확인**

```java
public boolean isEnd() {

    for (int i = 0; i < 9; i++) {

        if (panCount[i] != i) {
            return false;
        }
    }

    return true;
}
```

모든 배열의 값이 인덱스와 일치하면 퍼즐이 완성된 것으로 판단한다.

**버튼 이벤트 처리**

```java
@Override
public void actionPerformed(ActionEvent e) {

    if (e.getSource() == b2) {

        JOptionPane.showMessageDialog(
            this, "게임 종료합니다"
        );

        System.exit(0);
    }

    else if (e.getSource() == b1) {

        getRand();
        puzzleLayout();
        return;
    }

    for (int i = 0; i < 9; i++) {

        if (e.getSource() == btns[last]) {
            return;
        }

        if (e.getSource() == btns[i]) {

            panCount[i] = 8;

            panCount[last] =
                Integer.parseInt(btns[i].getText()) - 1;

            last = i;

            puzzleLayout();

            if (isEnd()) {
                JOptionPane.showMessageDialog(
                    this, "퍼즐 완성!"
                );
            }

            return;
        }
    }
}
```

위 코드는 수업에서 사용한 버튼 이벤트 처리 방식의 핵심을 보여주는 예시다. 실제 게임에서는 빈칸과 인접한 버튼만 이동하도록 검사하는 로직도 필요하다.

### 4-7. 퍼즐 게임 구현 시 주의사항

수업 코드의 난수 생성은 0~8을 중복 없이 배치하지만, 무작위 순열을 만들었다고 해서 모든 배열이 실제로 풀 수 있는 것은 아니다.

3×3 슬라이딩 퍼즐은 배치의 역전 개수(Inversion Count)를 검사해야 풀 수 있는 배열인지 판단할 수 있다.

따라서 완성도 있는 퍼즐 게임을 만들려면 다음 기능을 추가하는 것이 좋다.

- 빈칸과 상하좌우로 인접한 버튼만 이동 가능하도록 처리
- 퍼즐의 해결 가능 여부 검사
- 해결 불가능한 경우 다시 섞기
- 시작 및 종료 버튼 기능 분리
- 퍼즐 완성 여부 검사

## 5. 변수와 데이터형(Data Type)

### 5-1. 변수란?

변수는 데이터를 저장하기 위한 메모리 공간에 붙이는 이름이다.

```java
int age = 33;
String name = "홍길동";
```

- `int`: 데이터형
- `age`: 변수명
- `33`: 저장된 값

### 5-2. 변수의 종류

**① 인스턴스 변수(Instance Variable)**

객체마다 별도로 저장되는 변수다.

```java
class Student {

    int age;
    String name;

}
```

객체를 생성하면 객체마다 독립적인 값을 가진다.

**② 클래스 변수(Static Variable)**

`static` 키워드를 사용하며 클래스에 속하는 변수다.

```java
class Student {

    static int count = 0;

}
```

클래스의 모든 객체가 공유하는 변수다.

**③ 지역 변수(Local Variable)**

메소드나 특정 블록 내부에서 선언하는 변수다.

```java
public void display() {

    int a = 10;

}
```

선언된 블록 내부에서만 사용할 수 있으며, 사용하기 전에 반드시 초기화해야 한다.

**④ 매개변수(Parameter)**

메소드가 외부로부터 값을 전달받기 위해 선언하는 변수다.

```java
public void display(int a) {

    System.out.println(a);

}
```

### 5-3. 기본형과 참조형

Java의 데이터형은 크게 기본형과 참조형으로 나뉜다.

**① 기본형(Primitive Type)**

실제 값을 저장하는 데이터형이다.

| 구분 | 데이터형 |
|---|---|
| 정수형 | `byte`, `short`, `int`, `long` |
| 실수형 | `float`, `double` |
| 문자형 | `char` |
| 논리형 | `boolean` |

**② 참조형(Reference Type)**

객체를 참조하는 데이터형이다.

대표적인 예시는 다음과 같다.

- 배열
- 클래스
- 인터페이스
- 문자열(`String`)

```java
int[] arr = new int[5];

String name = "홍길동";
```

참조형 변수에는 객체를 가리키는 참조값이 저장된다.

### 5-4. 데이터형의 크기와 형변환

기본형의 대표적인 크기는 다음과 같다.

| 데이터형 | 크기 |
|---|---:|
| `byte` | 1바이트 |
| `short` | 2바이트 |
| `char` | 2바이트 |
| `int` | 4바이트 |
| `long` | 8바이트 |
| `float` | 4바이트 |
| `double` | 8바이트 |
| `boolean` | JVM 구현에 따라 달라질 수 있음 |

**① 자동 형변환(Promotion)**

표현할 수 있는 범위가 넓은 데이터형으로 변환하는 경우 자동 형변환이 가능하다.

```java
int a = 10;

double d = a;

System.out.println(d);
```

**실행 결과**

```text
10.0
```

**② 강제 형변환(Casting)**

큰 범위의 데이터형에서 작은 범위의 데이터형으로 변환할 때 명시적으로 형변환할 수 있다.

```java
double d = 10.5;

int a = (int)d;

System.out.println(a);
```

**실행 결과**

```text
10
```

소수점 이하 값은 버려진다.

### 5-5. 클래스의 형변환

클래스의 형변환은 상속 관계에서 가능하다.

```java
class A {
}

class B extends A {
}
```

**업캐스팅**

```java
A a = new B();
```

**다운캐스팅**

```java
A a = new B();

B b = (B)a;
```

단, 실제 객체가 `B`가 아니라면 `B`로 변환할 수 없다.

### 5-6. 클래스와 객체의 관계

```java
class Student {

    String name;

    public void study() {
        System.out.println("공부합니다.");
    }
}
```

객체 생성:

```java
Student s = new Student();

s.name = "홍길동";
s.study();
```

- 클래스: 객체를 만들기 위한 설계도
- 객체: 클래스를 기반으로 생성된 실체
- 인스턴스: 특정 클래스로부터 생성된 객체를 가리키는 표현

### 5-7. 메모리와 프로그램 구성

수업에서 다룬 프로그램 구성의 기본 관계는 다음과 같다.

```text
변수 + 메소드
     ↓
    클래스
     ↓
관련된 클래스의 묶음
     ↓
   패키지
```

관련된 기능을 메소드로 묶고, 변수와 메소드를 클래스로 구성하며, 여러 클래스를 패키지로 관리한다.

객체를 생성하면 일반적으로 객체의 인스턴스 데이터는 Heap 영역에 저장되고, 참조변수는 객체를 참조한다.

## 6. 가변인자(Varargs)

### 6-1. 가변인자란?

가변인자는 메소드에 전달하는 인자의 개수를 유동적으로 처리할 수 있는 문법이다.

`...` 기호를 사용한다.

```java
public static void display(int... a) {

}
```

일반적인 배열과 유사하게 메소드 내부에서 사용할 수 있다.

### 6-2. 가변인자 사용 예제

```java
public class VarargsTest {

    public static void display(int... a) {

        for (int i = 0; i < a.length; i++) {
            System.out.println(a[i]);
        }

    }

    public static void main(String[] args) {

        display(10);

        display(10, 20);

        display(10, 20, 30);

    }
}
```

**실행 결과**

```text
10

10
20

10
20
30
```

### 6-3. 가변인자의 특징

- 전달하는 인자의 개수를 자유롭게 지정할 수 있다.
- 메소드 내부에서는 배열처럼 사용할 수 있다.
- 인자를 전달하지 않아도 호출할 수 있다.
- 한 메소드에는 가변인자를 하나만 선언할 수 있다.
- 가변인자는 반드시 매개변수 목록의 마지막에 위치해야 한다.

```java
public void display(String name, int... score) {

}
```

다음과 같은 선언은 불가능하다.

```java
// 오류: 가변인자는 마지막에 위치해야 한다.
public void display(int... a, String name) {
}
```

### 6-4. 가변인자와 배열

가변인자는 내부적으로 배열 형태로 처리된다.

```java
public static void display(int... a) {

    System.out.println(a.length);

}
```

다음처럼 배열을 직접 전달하는 것도 가능하다.

```java
int[] arr = {10, 20, 30};

display(arr);
```
