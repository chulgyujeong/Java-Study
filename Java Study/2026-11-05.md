## 1. Java 라이브러리의 개념

### 1-1. 라이브러리란?

- 프로그램 개발에 필요한 기능을 미리 만들어 놓은 클래스의 집합
- 개발자가 모든 기능을 직접 구현하지 않고 기존 라이브러리를 활용
- 라이브러리는 표준화된 패키지, 클래스, 메소드 등을 제공

### 1-2. 라이브러리 구성 요소

| 구성 요소 | 설명 |
|---|---|
| 패키지(Package) | 관련된 클래스를 모아서 관리 |
| 클래스(Class) | 특정 기능을 수행하는 설계도 |
| 메소드(Method) | 클래스가 제공하는 기능 |
| 리턴형(Return Type) | 메소드 실행 결과의 데이터형 |
| 매개변수(Parameter) | 메소드에 전달하는 값 |
| 예외처리(Exception) | 실행 중 발생할 수 있는 오류 처리 |

### 1-3. 주요 Java 패키지

| 패키지 | 주요 기능 |
|---|---|
| java.lang | 기본 클래스 및 언어 관련 기능 |
| java.util | 컬렉션, 자료구조, 유틸리티 |
| java.text | 날짜 및 숫자 형식 처리 |
| java.lang.reflect | 리플렉션 |
| java.io | 파일 및 입출력 |
| java.net | 네트워크 통신 |
| java.sql | 데이터베이스 연동 |
| java.util.regex | 정규표현식 |

### 1-4. Java 플랫폼

- J2SE : Java 기본 라이브러리
- J2EE : 기업용 및 웹 애플리케이션 관련 기술
- Spring : Java 기반 웹 애플리케이션 개발 프레임워크

## 2. java.lang 패키지

### 2-1. java.lang이란?

- Java 프로그램에서 가장 많이 사용하는 기본 클래스들의 집합
- 별도의 import 없이 사용할 수 있는 패키지
- 컴파일러가 자동으로 `import java.lang.*;`을 처리

```java
// 생략 가능
import java.lang.*;

// 따라서 다음과 같이 사용 가능
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello Java");
    }
}
```

### 2-2. java.lang의 주요 클래스

| 클래스 | 기능 |
|---|---|
| Object | 모든 Java 클래스의 최상위 클래스 |
| String | 문자열 저장 및 제어 |
| StringBuffer | 동기화 기능을 지원하는 문자열 처리 |
| StringBuilder | 동기화 없이 빠르게 문자열 처리 |
| Integer | int 기본형을 객체로 표현 |
| Long | long 기본형을 객체로 표현 |
| Double | double 기본형을 객체로 표현 |
| Float | float 기본형을 객체로 표현 |
| Boolean | boolean 기본형을 객체로 표현 |
| Math | 수학 관련 기능 |
| System | 표준 입출력, 시스템 정보, GC 요청 등 |

### 2-3. Wrapper 클래스

기본형 데이터를 객체 형태로 사용할 수 있도록 제공하는 클래스

## 3. Object 클래스

### 3-1. Object란?

- Java의 모든 클래스가 상속받는 최상위 클래스
- 별도로 상속을 선언하지 않아도 자동으로 Object를 상속
- Object가 제공하는 메소드를 모든 클래스에서 사용할 수 있음

```java
public class A extends Object {

}
```

위 코드는 다음과 같이 생략할 수 있다.

```java
public class A {

}
```

### 3-2. Object의 주요 메소드

| 메소드 | 기능 |
|---|---|
| toString() | 객체 정보를 문자열로 반환 |
| equals() | 객체 비교 |
| hashCode() | 객체의 해시값 반환 |
| getClass() | 객체의 클래스 정보 반환 |
| clone() | 객체 복제 |
| finalize() | 객체 소멸 전 호출되던 메소드 (Deprecated) |

### 3-3. toString()

- 객체 정보를 문자열로 변환
- 출력문에서 객체를 출력하면 자동으로 호출
- 필요에 따라 오버라이딩하여 사용

```java
class A {
    String name;

    public A(String name) {
        this.name = name;
    }

    @Override
    public String toString() {
        return "이름 : " + name;
    }
}
```

```java
A a = new A("홍길동");

System.out.println(a);
```

### 3-4. equals()

- 객체가 같은지 비교하는 메소드
- Object의 기본 equals()는 객체의 참조값을 비교
- 필요에 따라 오버라이딩하여 객체 내부의 데이터 비교 가능

### 3-5. hashCode()

- 객체를 구분하기 위한 해시값을 반환
- HashMap, HashSet 등의 자료구조에서 활용
- equals()를 오버라이딩하면 hashCode()도 함께 오버라이딩하는 것이 원칙

**중요한 규칙**

- equals()가 true인 두 객체는 반드시 같은 hashCode()를 가져야 한다.
- hashCode()가 같다고 반드시 동일한 객체인 것은 아니다.

### 3-6. getClass()

객체의 클래스 정보를 확인하는 메소드

```java
A a = new A();

System.out.println(a.getClass());
System.out.println(a.getClass().getName());
```

## 4. 객체 비교와 메모리 주소

### 4-1. 객체 생성

객체는 `new 생성자()`를 통해 생성한다.

```java
class A {
    String name;

    public A(String name) {
        this.name = name;
    }
}

public class Main {
    public static void main(String[] args) {

        A a = new A("홍길동");
        A b = new A("홍길동");

        if (a == b) {
            System.out.println("동일하다");
        } else {
            System.out.println("다르다");
        }
    }
}
```

**실행 결과**

```text
다르다
```

### 4-2. 왜 다르다고 출력될까?

```java
A a = new A("홍길동");
A b = new A("홍길동");
```

- a와 b는 각각 별도의 new 연산자로 객체 생성
- 이름은 동일하지만 Heap 영역에 서로 다른 객체가 생성
- 따라서 참조하는 메모리 주소가 다름

### 4-3. ==와 equals() 비교

| 구분 | == | equals() |
|---|---|---|
| 기본형 | 실제 값 비교 | 사용 불가 |
| 참조형 | 참조값 비교 | 기본적으로 참조값 비교 |
| 목적 | 동일한 참조인지 확인 | 객체의 동등성 비교 |

**핵심**

```java
A a = new A("홍길동");
A b = new A("홍길동");

System.out.println(a == b);       // false
System.out.println(a.equals(b));  // false
```

Object의 기본 equals()는 ==와 동일한 참조 비교를 수행한다.

## 5. 객체 소멸과 Garbage Collection

### 5-1. 객체 생성과 활용

객체의 기본 사용 과정

1. 객체 생성 : `new 생성자()`
2. 객체 활용 : `객체명.메소드()`
3. 참조 제거 : `객체명 = null`
4. Garbage Collection을 통한 메모리 회수 가능

### 5-2. 객체 참조 제거

```java
Main m = new Main(100);

m.display();

m = null;
```

- m이 객체를 참조하지 않도록 변경
- 해당 객체를 다른 참조 변수도 참조하지 않는다면 GC의 수거 대상이 될 수 있음
- null을 대입했다고 즉시 메모리가 해제되는 것은 아님

### 5-3. Garbage Collection

- JVM이 사용하지 않는 객체의 메모리를 회수하는 기능
- 개발자가 직접 객체 메모리를 해제하지 않음
- GC 실행 시점은 JVM이 결정

```java
System.gc();
```

**주의사항**

- System.gc()는 Garbage Collection 실행을 요청하는 메소드
- 반드시 즉시 실행된다는 보장은 없음

### 5-4. finalize()

과거에는 객체가 소멸되기 전에 호출되는 메소드로 사용되었다.

```java
class Main {

    private int a = 10;

    public Main(int a) {
        this.a = a;
        System.out.println("객체 생성");
    }

    public void display() {
        System.out.println("Main:display() Call");
    }

    @Override
    protected void finalize() throws Throwable {
        System.out.println("객체 소멸");
    }
}
```

```java
public class MainTest {

    public static void main(String[] args) {

        Main m = new Main(100);

        m.display();

        m = null;

        System.gc();
    }
}
```

**주의사항**

- finalize()는 호출 시점이 보장되지 않는다.
- 최신 Java에서는 Deprecated된 기능이다.
- 현재는 try-with-resources와 AutoCloseable 등을 이용한 자원 관리를 권장한다.

## 6. 객체 복제 clone()

### 6-1. clone()이란?

- 기존 객체와 동일한 데이터를 가진 새로운 객체를 생성하는 기능
- Object 클래스에서 제공
- Cloneable 인터페이스를 구현해야 정상적으로 복제 가능

### 6-2. Cloneable 인터페이스

```java
class Sawon implements Cloneable {

    private int sabun;
    private String name;
    private String dept;

    public int getSabun() {
        return sabun;
    }

    public void setSabun(int sabun) {
        this.sabun = sabun;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public String getDept() {
        return dept;
    }

    public void setDept(String dept) {
        this.dept = dept;
    }

    public void print() {
        System.out.println("====== 사원 정보 ======");
        System.out.println("사번 : " + sabun);
        System.out.println("이름 : " + name);
        System.out.println("부서 : " + dept);
    }

    @Override
    protected Object clone() throws CloneNotSupportedException {
        return super.clone();
    }
}
```

### 6-3. clone() 사용

```java
public class Main {

    public static void main(String[] args) throws Exception {

        Sawon hong = new Sawon();

        hong.setSabun(1);
        hong.setName("홍길동");
        hong.setDept("개발부");

        hong.print();

        // 객체 복제
        Sawon shim = (Sawon) hong.clone();

        shim.print();

        // 복제된 객체는 별도의 객체
        System.out.println(hong == shim); // false
    }
}
```

### 6-4. clone()의 특징

- 새로운 객체 메모리를 생성
- 기존 객체의 필드값을 복사
- 기본적으로 얕은 복사(Shallow Copy)를 수행
- 참조형 필드가 있는 경우 내부 객체까지 별도로 복제되는 것은 아님

**얕은 복사와 깊은 복사**

| 구분 | 얕은 복사 | 깊은 복사 |
|---|---|---|
| 객체 | 새로운 객체 생성 | 새로운 객체 생성 |
| 기본형 필드 | 값 복사 | 값 복사 |
| 참조형 필드 | 참조값 복사 | 내부 객체까지 별도 복사 |
| 내부 객체 공유 | 공유함 | 공유하지 않음 |

### 6-5. 객체 참조와 복제의 차이

```java
Sawon hong = new Sawon();

Sawon shim = (Sawon) hong.clone();

Sawon kim = shim;
```

| 변수 | 메모리 관계 |
|---|---|
| hong | 독립적인 객체 |
| shim | hong을 복제한 새로운 객체 |
| kim | shim과 동일한 객체를 참조 |

```java
kim.setName("김두한");
```

kim과 shim은 같은 객체를 참조하므로 shim에서도 변경된 이름을 확인할 수 있다.

**핵심**

- clone() : 새로운 객체 생성
- 대입연산자(=) : 기존 객체의 참조값 복사

## 7. 참조형 데이터의 메모리 구조

### 7-1. 기본형과 참조형

| 구분 | 설명 | 종류 |
|---|---|---|
| 기본형 | 실제 데이터값을 저장 | int, double, char, boolean 등 |
| 참조형 | 객체를 참조하는 값 저장 | 배열, 클래스, 인터페이스 등 |

### 7-2. Stack과 Heap

**Stack 영역**
- 지역변수 및 참조변수 등이 저장되는 영역
- 메소드 호출과 종료에 따라 관리

**Heap 영역**
- new를 통해 생성한 객체와 배열 등이 저장되는 영역
- Garbage Collection의 관리 대상

```java
Member mm = new Member();
```

- mm : 참조변수
- new Member() : Heap 영역에 생성되는 객체
- mm은 생성된 객체를 참조

### 7-3. 참조변수의 특징

```java
Member a = new Member();
Member b = a;
```

a와 b는 동일한 객체를 참조한다.

```java
b.setName("홍길동");
```

a를 통해서도 변경된 이름을 확인할 수 있다.

## 8. 객체와 배열의 매개변수 전달

### 8-1. 객체를 매개변수로 전달

```java
public void memberUpdate(Member m) {

    m.setMno(1);
    m.setName("홍길동");
    m.setAddress("서울시 마포구");

}
```

호출 코드

```java
Member mm = new Member();

mm.memberUpdate(mm);

mm.print();
```

**핵심**

- Java는 메소드에 인자를 전달할 때 값을 복사한다.
- 객체를 전달하면 참조값이 복사된다.
- 복사된 참조값으로 동일한 객체의 데이터를 변경할 수 있다.

### 8-2. 배열을 매개변수로 전달

```java
public void arrayupdate(int[] arr) {

    for (int i = 0; i < arr.length; i++) {
        arr[i] = (int)(Math.random() * 100) + 1;
    }

    for (int i : arr) {
        System.out.print(i + " ");
    }
}
```

호출 코드

```java
int[] a = new int[5];

mm.arrayupdate(a);

System.out.println();

for (int i : a) {
    System.out.print(i + " ");
}
```

**핵심**

- 배열도 참조형 데이터이다.
- 메소드에 배열의 참조값이 복사되어 전달된다.
- 따라서 메소드 내부에서 배열의 요소를 변경하면 원본 배열에도 반영된다.
