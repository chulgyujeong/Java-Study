# 1. 클래스의 구성요소

## 1-1. 클래스란?

클래스는 데이터와 기능을 하나로 묶어 놓은 설계도이다.

- 데이터 저장: 변수
- 기능 수행: 메소드
- 객체 생성 및 초기화: 생성자

```java
class ClassName {

    // 변수
    int a;
    static int b;

    // 생성자
    ClassName() {
    }

    // 메소드
    void display() {
    }
}
```

## 1-2. 변수의 종류

### static 변수 (정적변수)

- 클래스에 하나만 생성된다.
- 모든 객체가 공동으로 사용한다.
- 객체 생성 없이 클래스명으로 접근할 수 있다.

```java
class A {
    static int a = 10;
}

A.a = 100;
```

### instance 변수 (인스턴스 변수)

- 객체마다 별도의 메모리 공간을 가진다.
- `new`를 이용해 객체를 생성할 때 만들어진다.
- 객체를 통해 접근한다.

```java
class A {
    int b = 100;
}

A aa = new A();
A bb = new A();

aa.b = 200;
bb.b = 300;
```

aa와 bb는 서로 다른 b를 가지고 있다.

## 1-3. 메소드

### static 메소드

클래스에 소속된 메소드이다.

```java
static void display() {
    System.out.println("공통 기능");
}
```

호출:

```java
A.display();
```

### instance 메소드

객체를 생성한 후 객체를 통해 호출한다.

```java
void display() {
    System.out.println("객체 기능");
}
```

호출:

```java
A aa = new A();
aa.display();
```

**핵심:** static 메소드는 인스턴스 변수에 직접 접근할 수 없다. 인스턴스 메소드는 static 변수와 인스턴스 변수 모두 사용할 수 있다.

# 2. 객체 생성과 메모리 구조

## 2-1. 객체 생성 방법

```java
class A {
    void display() {
        System.out.println("실행");
    }
}

A a = new A();
a.display();
```

구조:

- A: 사용자 정의 데이터형
- a: 객체를 참조하는 참조변수
- new: 객체를 생성하는 연산자
- A(): 생성자 호출

## 2-2. 객체의 생명주기

```text
객체 생성
   ↓
객체 활용
   ↓
참조 해제
   ↓
Garbage Collector에 의한 메모리 회수
```

```java
A a = new A();

a.display();

a = null;

System.gc();
```

주의:
- `a = null`은 객체 자체를 삭제하는 것이 아니라 참조를 끊는 것이다.
- `System.gc()`는 가비지 컬렉션을 요청하는 것이며 즉시 실행을 보장하지 않는다.
- 다른 참조변수가 같은 객체를 참조하고 있다면 해당 객체는 회수 대상이 아니다.

## 2-3. Java 메모리 구조

### Method Area

- 클래스 정보
- 메소드 관련 정보
- static 변수 등 클래스 수준의 정보

### Stack

- 지역변수
- 매개변수
- 메소드 호출 정보
- 참조변수

메소드 실행이 끝나면 해당 호출 프레임이 사라진다.

### Heap

- new로 생성한 객체
- 배열
- 인스턴스 변수 등 객체의 데이터

객체는 Heap에 생성되고 참조변수는 그 객체를 참조한다.

## 2-4. 객체와 지역변수 구분

```java
class A {

    int a = 100;

    void display() {

        int a = 10;

        System.out.println(a);
        System.out.println(this.a);
    }
}
```

출력:

```text
10
100
```

지역변수와 인스턴스 변수의 이름이 같으면 지역변수가 우선한다.

`this.a`를 사용하면 현재 객체의 인스턴스 변수에 접근할 수 있다.

## 2-5. static 변수와 instance 변수 실습

```java
class A {

    static int a = 10;
    int b = 100;

    static void display() {
        int a = 20;
        System.out.println(a + a);
    }

    void aaa() {
        a = 100;
        b = 200;
    }
}

public class Main {

    public static void main(String[] args) {

        A.display();

        A.a = 10;

        A aa = new A();
        A bb = new A();

        bb.a = 1000;
    }
}
```

결과 분석:

- `A.display()`의 결과는 40이다.
- 메소드 내부의 지역변수 a가 static 변수 a보다 우선한다.
- `A.a = 10`은 공유변수 값을 변경한다.
- `bb.a = 1000`도 static 변수의 값을 변경한다.
- 따라서 `aa.a`, `bb.a`, `A.a`는 모두 같은 값을 가리킨다.
- 반면 b는 객체마다 별도로 존재한다.

**권장:** static 변수는 `A.a`처럼 클래스명으로 접근한다.

# 3. 생성자와 초기화

## 3-1. 생성자란?

객체가 생성될 때 자동으로 호출되는 특별한 구성요소이다.

주요 역할:

- 인스턴스 변수 초기화
- 객체 생성 시 필요한 작업 수행
- 초기 데이터 설정
- 객체가 사용 가능한 상태가 되도록 준비

```java
class Student {

    int hakbun;
    String name;

    Student() {
        System.out.println("객체 생성");
    }
}
```

호출:

```java
Student s = new Student();
```

## 3-2. 생성자의 특징

1. 클래스명과 생성자명이 동일하다.
2. 반환형이 없다. (void도 작성하지 않는다.)
3. 객체 생성 시 호출된다.
4. 생성자는 여러 개 만들 수 있다.
5. 생성자 오버로딩을 지원한다.

```java
class Student {

    Student() {
    }

    Student(int hakbun) {
    }

    Student(String name) {
    }

    Student(int hakbun, String name) {
    }
}
```

## 3-3. 기본 생성자

생성자를 하나도 작성하지 않으면 컴파일러가 기본 생성자를 자동으로 제공한다.

```java
class Student {
}
```

위 코드는 다음과 같은 기본 생성자를 제공받는다.

```java
Student() {
}
```

단, 생성자를 하나라도 직접 작성하면 컴파일러가 기본 생성자를 자동으로 추가하지 않는다.

## 3-4. 생성자 오버로딩

매개변수의 개수나 데이터형을 다르게 하여 여러 생성자를 정의하는 방법이다.

```java
class Student {

    int hakbun;
    String name;

    Student() {
        hakbun = 0;
        name = "미정";
    }

    Student(int hakbun, String name) {
        this.hakbun = hakbun;
        this.name = name;
    }
}
```

## 3-5. 초기화 방법 3가지

### ① 명시적 초기화

```java
int a = 100;
```

### ② 초기화 블록

인스턴스 초기화 블록:

```java
{
    a = 200;
}
```

static 초기화 블록:

```java
static {
    b = 300;
}
```

### ③ 생성자

```java
A() {
    a = 400;
}
```

## 3-6. 초기화 실행 순서

```java
class A {

    int a = 100;
    static int b = 200;

    {
        a = 300;
        b = 400;
    }

    static {
        b = 500;
    }

    A() {
        a = 600;
        b = 700;
    }
}
```

기본적인 실행 순서:

1. 클래스 초기화 시 static 초기화
2. 객체 생성 시 인스턴스 변수의 명시적 초기화
3. 인스턴스 초기화 블록
4. 생성자 실행

주의:
- static 초기화 블록은 클래스 초기화 시 한 번 실행된다.
- 인스턴스 초기화 블록은 객체를 생성할 때마다 실행된다.
- static 블록에서는 인스턴스 변수를 직접 사용할 수 없다.

# 4. 변수의 종류

| 구분 | 지역변수 | 인스턴스 변수 | static 변수 |
|---|---|---|---|
| 선언 위치 | 메소드 내부 등 | 클래스 내부 | 클래스 내부 |
| 메모리 | Stack 프레임 | Heap 객체 | 클래스 수준 |
| 생성 시점 | 선언 및 실행 시 | 객체 생성 시 | 클래스 초기화 시 |
| 초기값 | 자동 초기화 안 됨 | 기본값 제공 | 기본값 제공 |
| 공유 여부 | 공유 안 함 | 객체별 독립 | 모든 객체 공유 |

기본형 변수의 기본값:

| 데이터형 | 기본값 |
|---|---|
| int | 0 |
| double | 0.0 |
| char | '\u0000' |
| boolean | false |
| 참조형 | null |

지역변수는 반드시 초기화한 후 사용해야 한다.

# 5. 접근 지정어와 제어어

## 5-1. 접근 지정어

| 접근 지정어 | 같은 클래스 | 같은 패키지 | 다른 패키지의 자식 클래스 | 전체 |
|---|---|---|---|---|
| private | O | X | X | X |
| default | O | O | X | X |
| protected | O | O | O* | X |
| public | O | O | O | O |

*protected는 다른 패키지의 자식 클래스에서도 상속 관계에 따른 접근 조건을 만족해야 한다.

### private

자신의 클래스 내부에서만 접근 가능하다.

### default

접근 지정어를 생략한 경우이며 같은 패키지에서 접근 가능하다.

### protected

같은 패키지 및 다른 패키지의 상속 관계에서 조건에 따라 접근 가능하다.

### public

모든 클래스에서 접근 가능하다.

## 5-2. 제어어

| 제어어 | 의미 |
|---|---|
| static | 클래스에 소속 |
| final | 변경 또는 확장 제한 |
| abstract | 추상적인 구성요소 |

### static

공유 변수 및 클래스 메소드에 사용한다.

### final

- 변수: 값 변경 불가
- 메소드: 오버라이딩 제한
- 클래스: 상속 제한

### abstract

구현이 없는 추상 메소드나 추상 클래스에 사용한다.

# 6. 객체지향 프로그래밍의 3대 특성

## 6-1. 캡슐화 (Encapsulation)

데이터를 외부에서 직접 접근하지 못하도록 보호하는 개념이다.

주로 private과 Getter, Setter를 이용한다.

## 6-2. 상속 (Inheritance)

기존 클래스의 기능을 재사용하고 새로운 기능을 확장하는 개념이다.

```java
class A {
    int a;
}

class B extends A {
    int b;
}
```

B는 A의 상속 가능한 멤버를 활용할 수 있다.

## 6-3. 다형성 (Polymorphism)

하나의 타입으로 다양한 객체를 처리하거나 같은 메소드 호출이 서로 다른 방식으로 동작하는 특성이다.

대표적인 방법:

- 오버로딩
- 오버라이딩

### 오버로딩

같은 이름의 메소드를 매개변수를 다르게 하여 여러 개 정의한다.

```java
void display() {
}

void display(int a) {
}

void display(String s) {
}
```

### 오버라이딩

상속받은 부모 메소드를 자식 클래스에서 재정의한다.

```java
class A {
    void display() {
        System.out.println("A");
    }
}

class B extends A {

    @Override
    void display() {
        System.out.println("B");
    }
}
```

# 7. 상속과 this, super

## 7-1. 상속 구조

```java
class A {

    int a, b, c;
}

class B extends A {

    int d, e, f;
}
```

```java
B b = new B();
```

B 객체에는 부모 클래스 A에서 상속받은 멤버와 자식 클래스 B의 멤버가 함께 존재한다.

## 7-2. this

현재 객체 자신을 의미한다.

```java
class Student {

    int hakbun;

    Student(int hakbun) {
        this.hakbun = hakbun;
    }
}
```

## 7-3. super

부모 클래스의 멤버에 접근할 때 사용한다.

```java
class A {

    int a = 100;
}

class B extends A {

    int a = 200;

    void display() {
        System.out.println(this.a);
        System.out.println(super.a);
    }
}
```

출력:

```text
200
100
```

## 7-4. 생성자에서 super()

부모 클래스 생성자를 호출한다.

```java
class A {

    A(int a) {
        System.out.println(a);
    }
}

class B extends A {

    B() {
        super(10);
    }
}
```

주의:
- `super()`는 자식 생성자의 첫 번째 문장이어야 한다.
- 명시하지 않으면 컴파일러가 부모의 기본 생성자를 호출하려고 한다.
- 부모에게 기본 생성자가 없다면 적절한 `super(인자)`를 작성해야 한다.

# 8. 캡슐화와 Getter, Setter

## 8-1. 캡슐화의 목적

데이터를 보호하고 외부에서 정해진 방법으로만 접근하도록 만드는 것이다.

```java
class Sawon {

    private int sabun;
    private String name;

    public int getSabun() {
        return sabun;
    }

    public void setSabun(int sabun) {
        this.sabun = sabun;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}
```

## 8-2. 사용 방법

```java
Sawon s = new Sawon();

s.setSabun(1);
s.setName("홍길동");

System.out.println(s.getName());
System.out.println(s.getSabun());
```

- Getter: 데이터 읽기
- Setter: 데이터 변경

## 8-3. Lombok

Getter, Setter 등을 자동 생성하는 라이브러리이다.

```java
import lombok.Data;

@Data
public class Sawon {

    private int sabun;
    private String name;

    protected String job;
    String dept;
    public int pay;
}
```

`@Data`는 Getter, Setter 외에도 toString, equals, hashCode 등의 메소드를 생성한다.

# 9. 배열과 객체 배열

## 9-1. 기본 배열

```java
int[] arr = new int[5];
```

배열은 동일한 데이터형을 여러 개 저장하는 자료구조이다.

## 9-2. 객체 배열

```java
class Student {

    int hakbun;
    String name;
}

Student[] std = new Student[3];
```

주의: 위 코드는 Student 객체 3개를 생성한 것이 아니다. Student 참조변수 3개를 저장할 배열을 생성한 것이다.

실제 객체 생성:

```java
std[0] = new Student();
std[1] = new Student();
std[2] = new Student();
```

## 9-3. 객체 배열 실습

```java
Student s1 = new Student(1, "홍길동", 90, 90, 90);
```

# 10. 컬렉션과 ArrayList

## 10-1. 컬렉션이란?

객체를 효율적으로 저장하고 관리하기 위한 자료구조이다.

대표적인 컬렉션:

- List
- Set
- Map

## 10-2. ArrayList

데이터를 순서대로 저장하며 중복을 허용한다.

```java
List<Student> list = new ArrayList<>();

list.add(s1);
list.add(s2);
list.add(s3);
```

데이터 읽기:

```java
Student s = list.get(0);
```

데이터 개수:

```java
System.out.println(list.size());
```

데이터 삭제:

```java
list.remove(0);
```

전체 출력:

```java
for (Student s : list) {
    System.out.println(s.name);
}
```

## 10-3. 제네릭

```java
List<Student> list = new ArrayList<>();
```

`<Student>`는 해당 컬렉션에서 Student 타입을 사용하겠다는 의미이다.

제네릭을 사용하면 불필요한 형변환을 줄이고 데이터형 안정성을 높일 수 있다.

## 12-4. MelonMusic

Music을 상속받아 멜론 데이터를 수집한다.

```java
public class MelonMusic extends Music {

    public MelonMusic() {

        try {

            Document doc = Jsoup
                .connect("https://www.melon.com/chart/index.htm")
                .get();

            Elements title =
                doc.select("tr#lst50 div.rank01 a");

            Elements singer =
                doc.select("tr#lst50 div.rank02 span.checkEllipsis");

            Elements album =
                doc.select("tr#lst50 div.rank03 a");

            Elements poster =
                doc.select("tr#lst50 div.wrap img");

            for (int i = 0; i < title.size(); i++) {

                musics[i] = new MusicVO();

                musics[i].setTitle(title.get(i).text());
                musics[i].setSinger(singer.get(i).text());
                musics[i].setPoster(poster.get(i).attr("src"));
                musics[i].setAlbum(album.get(i).text());
                musics[i].setRank(i + 1);
            }

        } catch (Exception ex) {
            ex.printStackTrace();
        }
    }
}
```

핵심 개념:

- extends: 상속
- 생성자: 객체 생성 시 데이터 수집
- Jsoup: 웹 페이지 HTML 분석
- Elements: HTML 요소 집합
- select(): CSS 선택자로 데이터 추출
- get(i): 특정 요소 접근
- text(): 텍스트 추출
- attr(): HTML 속성 추출

```java
public class MovieSystem {

    private static Movie[] movies = new Movie[1938];

    // 전체 목록
    public Movie[] movieListData() {
        return movies;
    }

    // 상세보기
    public Movie movieDetailData(int mno) {
        return movies[mno - 1];
    }

    // 영화 검색
    public Movie[] movieFindData(String fd) {

        int count = 0;

        for (Movie m : movies) {

            if (m != null && m.getTitle().contains(fd)) {
                count++;
            }
        }

        Movie[] result = new Movie[count];

        int i = 0;

        for (Movie m : movies) {

            if (m != null && m.getTitle().contains(fd)) {
                result[i++] = m;
            }
        }

        return result;
    }
}
```

## 13-4. MovieSystem의 데이터 초기화

```java
static {

    try {

        FileReader fr =
            new FileReader("c:\\javaDev\\movie.txt");

        StringBuffer sb = new StringBuffer();

        int i = 0;

        while ((i = fr.read()) != -1) {
            sb.append((char)i);
        }

        fr.close();

        String[] movie = sb.toString().split("\n");

        i = 0;

        for (String m : movie) {

            String[] info = m.split("\\|");

            movies[i] = new Movie();

            movies[i].setMno(Integer.parseInt(info[0]));
            movies[i].setTitle(info[1]);
            movies[i].setGenre(info[2]);
            movies[i].setActor(info[4]);
            movies[i].setRegdate(info[5]);
            movies[i].setGrade(info[6]);
            movies[i].setDirector(info[7]);

            i++;
        }

    } catch (Exception ex) {
        ex.printStackTrace();
    }
}
```
