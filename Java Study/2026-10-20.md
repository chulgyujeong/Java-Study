## 1. 반복 제어문

반복문 실행 중 특정 조건에 따라 반복을 종료하거나 현재 반복을 건너뛸 때 사용한다.

1-1. break와 continue

구분	설명

break	가장 가까운 반복문을 종료

continue	현재 반복의 남은 코드를 건너뛰고 다음 반복으로 이동

// break: 반복문 종료

for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;
    }
    System.out.print(i + " ");
}
// 결과: 1 2 3 4

// continue: 현재 반복 건너뛰기
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        continue;
    }
    System.out.print(i + " ");
}
// 결과: 1 2 3 4 6 7 8 9 10


**주의사항**

break, continue 뒤에 같은 블록에서 실행할 수 없는 코드를 작성하면 도달 불가능 코드 오류가 발생한다.
for문에서는 continue 실행 후 증감식으로 이동한다.
while, do-while문에서는 continue 이후 조건 검사로 이동하므로 반복 변수의 증감 위치에 주의한다.

1-2. 무한 루프

반복 조건이 계속 참이거나 종료 조건이 없는 경우 반복문이 무한히 실행된다.

while (true) {
    // 반복할 코드
    break;
}

for (;;) {
    // 반복할 코드
    break;
}

1-3. 중첩 반복문과 Label

기본 break와 continue는 가장 가까운 반복문에 적용된다.

Label을 사용하면 바깥쪽 반복문까지 제어할 수 있다.

outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) {
            break outer;
        }
    }
}

break outer: outer로 지정한 반복문 전체 종료
continue outer: outer 반복문의 다음 반복으로 이동

# 2. 반복 제어문 실습

2-1. 입력값 유효성 검사

점수는 0~100 사이의 정수만 입력하도록 제한한다.

Scanner scan = new Scanner(System.in);
int kor;

while (true) {
    System.out.print("국어 입력: ");
    kor = scan.nextInt();

    if (kor < 0 || kor > 100) {
        System.out.println("잘못된 입력입니다.");
        continue;
    }

    break;
}


**핵심 개념**

while (true): 올바른 값이 입력될 때까지 반복
continue: 잘못된 입력이면 다시 입력
break: 올바른 입력이면 반복 종료
||: 두 조건 중 하나라도 참이면 참

2-2. 총점, 평균, 학점 계산

int total = kor + eng + math;
double avg = total / 3.0;

System.out.println("총점: " + total);
System.out.printf("평균: %.2f%n", avg);

char score;

switch ((int) avg / 10) {
    case 10, 9 -> score = 'A';
    case 8 -> score = 'B';
    case 7 -> score = 'C';
    case 6 -> score = 'D';
    default -> score = 'F';
}

정수끼리 나누면 소수점 이하가 버려진다.
평균을 실수로 계산하려면 3.0으로 나눈다.
%.2f: 소수점 둘째 자리까지 출력한다.
case 10, 9 ->: Java의 화살표식 switch 문법을 사용한다.

2-3. Up & Down 게임

1~100 사이의 난수를 생성하고 사용자 입력값과 비교한다.

int com = (int) (Math.random() * 100) + 1;

조건	결과
com > user	더 큰 수 입력 (UP)
com < user	더 작은 수 입력 (DOWN)
com == user	정답, 게임 종료

**핵심 개념** : Math.random(), 조건문, continue, break, 무한 반복문

# 3. Java 메모리 구조와 변수

3-1. 변수의 종류

구분	설명	예시

기본형	실제 값 자체를 저장	int, double, char, boolean

참조형	객체 등을 참조하는 값 저장	String, 배열, 클래스 객체

3-2. 메모리 구조

영역	주요 역할
Method Area	클래스 정보, 런타임 상수 풀, 정적 변수 관련 정보 등

Java에서는 일반적으로 delete, free()를 직접 호출해 객체 메모리를 해제하지 않는다.

3-3. String 비교

String s1 = "Java";
String s2 = "Java";
String s3 = new String("Java");

System.out.println(s1 == s2);      // true
System.out.println(s1 == s3);      // false
System.out.println(s1.equals(s3)); // true

==: 참조값 비교
equals(): 문자열 내용 비교
문자열 리터럴은 문자열 풀(String Pool)을 통해 동일한 리터럴을 공유할 수 있다.
new String()은 일반적으로 별도의 String 객체를 생성한다.

## 4. String 클래스

String은 문자열을 다루는 클래스이며, 생성된 문자열 객체의 내용은 변경할 수 없다(불변성).

4-1. 문자열과 인덱스
String msg = "Hello Java";


문자열의 인덱스는 0부터 시작한다.

메소드	설명	예시
charAt(index)	지정한 위치의 문자 반환	msg.charAt(0) → H
length()	문자열 길이 반환	msg.length() → 10
for (int i = 0; i < msg.length(); i++) {
    System.out.println(msg.charAt(i));
}

4-2. 문자열 비교 메소드

메소드	설명

equals()	문자열 내용 비교, 대소문자 구분

equalsIgnoreCase()	대소문자 구분 없이 비교

String s1 = "Hello Java";
String s2 = "hello java";
System.out.println(s1.equals(s2));            // false
System.out.println(s1.equalsIgnoreCase(s2));  // true

4-3. 문자열 검색 메소드

메소드	설명	예시

contains()	특정 문자열 포함 여부	s.contains("Java")

startsWith()	특정 문자열로 시작하는지 확인	s.startsWith("Hello")

endsWith()	특정 문자열로 끝나는지 확인	s.endsWith("Java")

세 메소드 모두 결과를 boolean으로 반환한다.

활용 예시

contains(): 검색어 포함 여부 확인
startsWith(): 접두어 검색 및 자동 완성
endsWith(): 파일 확장자 확인

## 5. 문자열 처리 실습

5-1. 간단한 로그인 구현

String myId = "hong";
String myPwd = "1234";

String id = JOptionPane.showInputDialog("아이디 입력:");
String pwd = JOptionPane.showInputDialog("비밀번호 입력:");

if (id != null && pwd != null
        && id.equalsIgnoreCase(myId)
        && pwd.equals(myPwd)) {
    JOptionPane.showMessageDialog(null, "로그인되었습니다.");
} else {
    JOptionPane.showMessageDialog(null, "아이디나 비밀번호가 틀립니다.");
}

JOptionPane.showInputDialog(): 입력 창 표시
JOptionPane.showMessageDialog(): 메시지 창 표시
아이디는 대소문자를 구분하지 않고 비교한다.
비밀번호는 대소문자를 구분하여 비교한다.
실제 서비스에서는 비밀번호를 코드에 하드코딩하지 않고 안전하게 저장·검증해야 한다.

5-2. 웹 크롤링과 문자열 검색

Jsoup을 사용하면 웹 페이지를 가져와 HTML 요소를 선택할 수 있다.

Document doc = Jsoup.connect(url).get();

Elements title = doc.select("table.list-wrap a.title");
Elements singer = doc.select("table.list-wrap a.artist");

for (int i = 0; i < title.size(); i++) {
    if (title.get(i).text().contains(keyword)) {
        System.out.println(
            title.get(i).text() + " (" + singer.get(i).text() + ")"

}

Jsoup.connect(url).get(): 웹 페이지 요청
doc.select(): CSS 선택자로 HTML 요소 검색
Elements: 검색된 요소들의 모음
.text(): 요소의 텍스트 추출
contains(), startsWith(), endsWith(): 추출한 문자열 검색

## 6. 문자열 변환 메소드

6-1. 대소문자 변환

메소드	설명

toUpperCase()	대문자로 변환

toLowerCase()	소문자로 변환

String alpha = "Hello Java";
System.out.println(alpha.toUpperCase()); // HELLO JAVA
System.out.println(alpha.toLowerCase()); // hello java
System.out.println(alpha);               // Hello Java


원본 문자열은 변경되지 않으며, 변환 결과를 사용하려면 반환값을 저장해야 한다.

6-2. 문자열 치환

메소드	설명

replace()	문자 또는 문자열 치환

replaceAll()	정규식에 일치하는 부분 치환

String msg = "Hello Java!!";

System.out.println(msg.replace('a', 'b'));
// Hello Jbvb!!

System.out.println(msg.replace("Java", "Oracle"));
// Hello Oracle!!


replaceAll()은 정규식을 활용할 수 있다.

String s = "ABCD가나다라12345";

System.out.println(s.replaceAll("[가-힣]", "0"));
System.out.println(s.replaceAll("[A-Z]", " "));
System.out.println(s.replaceAll("[0-9]", " "));
System.out.println(s.replaceAll("[^가-힣]", " "));

6-3. 자주 사용하는 정규식
정규식	의미

[가-힣]	한글 음절 한 글자

[A-Z]	영문 대문자

[a-z]	영문 소문자

[A-Za-z]	영문 대소문자

[0-9]	숫자 한 자리

[^가-힣]	한글 음절이 아닌 문자

[0-9]{1,3}	숫자 1~3자리

정규식의 .은 일반적으로 임의의 문자 하나를 의미하므로, 마침표 자체를 나타내려면 \\.처럼 이스케이프한다.

## 7. 문자열 자르기

substring()은 문자열의 일부를 추출할 때 사용한다.

메소드	설명

substring(int start)	시작 인덱스부터 끝까지 추출

substring(int start, int end)	시작 인덱스부터 끝 인덱스 직전까지 추출

String s = "Hello Java";

System.out.println(s.substring(6));    // Java
System.out.println(s.substring(0, 5)); // Hello


**주의사항**

인덱스는 0부터 시작한다.
substring(start, end)에서 start는 포함하고 end는 포함하지 않는다.
유효하지 않은 인덱스를 사용하면 StringIndexOutOfBoundsException이 발생할 수 있다.

**핵심 요약**

break: 반복문 종료

continue: 현재 반복 건너뛰기

==: 참조값 비교

equals(): 문자열 내용 비교

charAt(), length(): 문자 추출 및 길이 확인
contains(), startsWith(), endsWith(): 문자열 검색
replace(), replaceAll(): 문자열 치환
substring(): 문자열 자르기
