# 1. Annotation (어노테이션)

## 1-1. 어노테이션 개념

- `@` 기호를 사용하여 클래스, 메소드, 변수 등에 정보를 표시하는 기능
- 프로그램에서 특정 요소를 구분하고 식별하는 역할
- 리플렉션과 결합하여 실행 시점에 정보를 읽고 활용 가능
- Spring, SpringBoot, MyBatis 등에서 활용

## 1-2. 유지 정책 (Retention)

| 종류 | 설명 |
|---|---|
| SOURCE | 소스 코드에만 존재하며 컴파일 후 사라짐 |
| CLASS | 클래스 파일까지 유지되지만 실행 중 리플렉션으로 읽을 수 없음 |
| RUNTIME | 실행 중에도 유지되며 리플렉션으로 읽을 수 있음 |

## 1-3. 적용 대상 (Target)

| 종류 | 적용 대상 |
|---|---|
| TYPE | 클래스, 인터페이스 등 |
| METHOD | 메소드 |
| CONSTRUCTOR | 생성자 |
| FIELD | 멤버 변수 |
| PARAMETER | 매개변수 |

## 1-4. 사용자 정의 어노테이션

```java
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface REquestMapping {
    public String value();
}
```

- `@Retention`: 어노테이션 유지 정책 설정
- `@Target`: 어노테이션 적용 위치 설정
- `value()`: 어노테이션에 전달할 값

## 1-5. 실습 내용

- 사용자 정의 어노테이션 생성
- 메소드에 어노테이션 적용
- 리플렉션을 이용한 어노테이션 정보 확인

**실습 클래스**
- `REquestMapping.java`
- `어노테이션_1.java`

# 2. Java Text Format (문자열 및 데이터 형식 변환)

## 2-1. java.text 패키지

Java에서 날짜, 숫자, 문자열 등의 출력 형식을 변경할 때 사용하는 라이브러리

| 클래스 | 주요 기능 |
|---|---|
| SimpleDateFormat | 날짜 및 시간 형식 변경 |
| DecimalFormat | 숫자 형식 변경 |
| NumberFormat | 숫자, 통화, 백분율 형식 변경 |
| MessageFormat | 문자열에 데이터 삽입 |
| ChoiceFormat | 조건에 따른 문자열 선택 |

## 2-2. SimpleDateFormat

날짜 및 시간 형식을 지정하여 출력

| 패턴 | 의미 | 예시 |
|---|---|---|
| yyyy | 4자리 연도 | 2026 |
| yy | 2자리 연도 | 26 |
| MM | 월 | 11 |
| dd | 일 | 11 |
| HH | 24시간제 | 17 |
| hh | 12시간제 | 05 |
| mm | 분 | 30 |
| ss | 초 | 20 |

```java
Date date = new Date();

SimpleDateFormat sdf =
    new SimpleDateFormat("yy/MM/dd HH:mm:ss");

System.out.println(sdf.format(date));
```

## 2-3. DecimalFormat

숫자에 천 단위 구분 기호 등을 적용

```java
DecimalFormat df =
    new DecimalFormat("###,###,###");

int won = 1000000000;

System.out.println(df.format(won) + "원");
```

출력 예시: `1,000,000,000원`

## 2-4. MessageFormat

문자열 내부에 여러 데이터를 삽입할 때 사용

```java
String sql =
    "INSERT INTO member VALUES({0},''{1}'',''{2}'')";

Object[] obj = {1, "홍길동", "남자"};

System.out.println(MessageFormat.format(sql, obj));
```

- `{0}`, `{1}`, `{2}` 형식으로 데이터 위치 지정
- JDBC의 PreparedStatement와는 다른 기능

## 2-5. ChoiceFormat

조건별로 문자열을 선택할 때 사용

```java
double[] limits = {0, 60, 70, 80, 90};

String[] formats = {"F", "D", "C", "B", "A"};

ChoiceFormat cf = new ChoiceFormat(limits, formats);

System.out.println(cf.format(100));
```

## 2-6. NumberFormat

숫자, 통화, 백분율 형식 변경

```java
double num = 1234567.89;

NumberFormat nf = NumberFormat.getInstance();
System.out.println(nf.format(num));

nf = NumberFormat.getCurrencyInstance();
System.out.println(nf.format(num));

nf = NumberFormat.getPercentInstance();
System.out.println(nf.format(0.25));
```

## 2-7. 실무 활용

- 게시판 등록일 및 수정일
- 쇼핑몰 상품 가격 및 결제 금액
- 회원 정보 출력
- 예약 날짜 및 시간
- 데이터베이스 SQL 문자열 구성

# 3. Reflection (리플렉션)

## 3-1. 리플렉션 개념

실행 중인 프로그램에서 클래스의 정보를 읽고 객체, 변수, 생성자, 메소드를 동적으로 제어하는 기술

주요 활용 프레임워크

- Spring / SpringBoot
- MyBatis
- JPA

## 3-2. 리플렉션 주요 구성 요소

| 클래스 | 역할 |
|---|---|
| Class | 클래스 정보 확인 |
| Field | 멤버 변수 정보 및 값 제어 |
| Constructor | 생성자 정보 및 객체 생성 |
| Method | 메소드 정보 및 호출 |

## 3-3. Class 객체 얻기

```java
// 1. 클래스명.class
Class cls1 = String.class;

// 2. 객체.getClass()
String str = "";
Class cls2 = str.getClass();

// 3. Class.forName()
Class cls3 = Class.forName("java.lang.String");
```

## 3-4. 생성자를 이용한 객체 생성

```java
Class cls = Class.forName("com.sist.reflect.Member");

Object obj = cls.getDeclaredConstructor(
    int.class, String.class, String.class
).newInstance(2, "박문수", "부산");
```

- `getDeclaredConstructor()`: 생성자 정보 확인
- `newInstance()`: 생성자를 호출하여 객체 생성

## 3-5. Field를 이용한 멤버 변수 제어

```java
Field f = cls.getDeclaredField("address");

f.setAccessible(true);

f.set(obj, "제주");

System.out.println(f.get(obj));
```

- `getDeclaredField()`: 특정 변수 정보 가져오기
- `setAccessible(true)`: 접근 제한 해제 시도
- `set()`: 변수값 변경
- `get()`: 변수값 읽기

## 3-6. Method를 이용한 메소드 제어

```java
Method m = cls.getMethod("info");

m.invoke(obj);
```

- `getMethod()`: public 메소드 검색
- `getDeclaredMethods()`: 선언된 메소드 전체 검색
- `invoke()`: 메소드 호출

## 3-7. 리플렉션의 장단점

**장점**
- 동적 객체 생성
- 동적 메소드 호출
- 코드 재사용성 향상
- 프레임워크 자동화 구현에 활용

**단점**
- 일반적인 직접 호출보다 복잡함
- 실행 성능 오버헤드 발생 가능
- 코드 가독성 저하
- 접근 제한을 우회할 경우 보안 문제 발생 가능

## 3-8. 어노테이션과 리플렉션 결합

어노테이션으로 메소드를 구분하고 리플렉션으로 해당 메소드를 실행하는 방식

실습 흐름

1. 클래스 정보 읽기
2. 객체 생성
3. 메소드 전체 검색
4. 메소드에 설정된 어노테이션 확인
5. 어노테이션 값 비교
6. 조건에 맞는 메소드 실행

```java
Method[] methods = clsName.getDeclaredMethods();

for (Method m : methods) {
    REquestMapping rm =
        m.getAnnotation(REquestMapping.class);

    if (rm != null &&
        rm.value().equals(String.valueOf(menu))) {
        m.invoke(obj);
    }
}
```

# 4. Regular Expression (정규표현식)

## 4-1. 정규표현식 개념

특정한 패턴을 이용하여 문자열을 검색하거나 검사하는 기술

주요 활용 분야

- 회원가입 유효성 검사
- 전화번호 및 이메일 검증
- 웹 크롤링 데이터 추출
- 문자열 검색 및 치환
- 데이터 정제 및 분석

## 4-2. 정규표현식 주요 기호

| 기호 | 의미 | 예시 |
|---|---|---|
| `[abc]` | a, b, c 중 한 문자 | `[abc]` |
| `[A-Z]` | 영문 대문자 | `[A-Z]` |
| `[a-z]` | 영문 소문자 | `[a-z]` |
| `[0-9]` | 숫자 | `[0-9]` |
| `[가-힣]` | 한글 | `[가-힣]` |
| `\d` | 숫자 | `\d` |
| `\s` | 공백 문자 | `\s` |
| `\w` | 영문자, 숫자, 밑줄 | `\w` |
| `.` | 줄바꿈을 제외한 임의의 한 문자 | `h..llo` |
| `?` | 0회 또는 1회 | `colou?r` |
| `*` | 0회 이상 | `[A-Z]*` |
| `+` | 1회 이상 | `[A-Z]+` |
| `{n}` | 정확히 n회 | `[A-Z]{3}` |
| `{n,m}` | n회 이상 m회 이하 | `[0-9]{1,3}` |
| `|` | OR 조건 | `dog|cat` |
| `^` | 문자열 시작 | `^홍` |
| `$` | 문자열 끝 | `동$` |
| `()` | 그룹 지정 | `(abc)+` |

## 4-3. Pattern과 Matcher

```java
Pattern p = Pattern.compile("맛있[가-힣]*");

Matcher m = p.matcher(res);

while (m.find()) {
    System.out.println(m.group());
}
```

| 메소드 | 역할 |
|---|---|
| `Pattern.compile()` | 정규표현식 패턴 생성 |
| `pattern.matcher()` | 검사 대상 문자열 지정 |
| `find()` | 패턴에 일치하는 문자열 검색 |
| `group()` | 검색된 문자열 반환 |
| `matches()` | 전체 문자열이 패턴과 일치하는지 검사 |

## 4-4. 데이터 추출 및 치환

**숫자만 추출**

```java
String price = "가격: 30,000원";

String s = price.replaceAll("[^0-9]", "");

System.out.println(s);
```

출력: `30000`

**문자열 분리**

```java
String res = "홍길동|남자|30|서울|010-1111-1111";

String[] info = res.split("\\|");

for (String i : info) {
    System.out.println(i);
}
```

## 4-5. 문자열 패턴 검사

```java
System.out.println("hello".matches("h..lo"));

System.out.println("홍길동".matches("^홍[가-힣]+"));

System.out.println("dog".matches("dog|cat|pig"));

System.out.println("abcabc".matches("(abc)+"));
```

## 4-6. 그룹 및 반복 패턴

```java
System.out.println("hahahe".matches("(ha)+he"));

System.out.println("a1b2c3".matches("(\\w\\d)+"));

System.out.println("123123".matches("(\\d+)+"));
```

## 4-7. 정규표현식과 데이터베이스

**SQL LIKE**

```sql
WHERE name LIKE '%맛있고%'
```

**Oracle REGEXP_LIKE**

```sql
WHERE REGEXP_LIKE(name, '[A-E]')
```

- LIKE: 단순 문자열 패턴 검색
- REGEXP_LIKE: 정규표현식 기반 검색

# 5. Java Time API (날짜 및 시간 처리)

## 5-1. java.time 패키지

Java 8부터 제공하는 날짜 및 시간 처리 API

| 클래스 | 기능 |
|---|---|
| LocalDate | 날짜 |
| LocalTime | 시간 |
| LocalDateTime | 날짜 + 시간 |
| DateTimeFormatter | 날짜 및 시간 형식 변환 |

## 5-2. 현재 날짜 및 시간

```java
LocalDateTime now = LocalDateTime.now();

System.out.println(now);
```

## 5-3. 특정 날짜 및 시간 생성

```java
LocalDateTime dateTime =
    LocalDateTime.of(2026, 11, 11, 12, 30, 30);

System.out.println(dateTime);
```

## 5-4. 날짜 및 시간 연산

```java
LocalDateTime now = LocalDateTime.now();

// 7일 후, 3시간 전
LocalDateTime f = now.plusDays(7).plusHours(-3);

// 1개월 전
LocalDateTime p = now.minusMonths(1);
```

주요 메소드

- `plusDays()`: 날짜 더하기
- `plusMonths()`: 월 더하기
- `plusYears()`: 연도 더하기
- `plusHours()`: 시간 더하기
- `minusMonths()`: 월 빼기
- `minusDays()`: 날짜 빼기

## 5-5. 날짜 및 시간 데이터 추출

```java
LocalDateTime now = LocalDateTime.now();

int year = now.getYear();
int month = now.getMonthValue();
int day = now.getDayOfMonth();
int hour = now.getHour();
```

## 5-6. DateTimeFormatter

날짜 및 시간 출력 형식 지정

```java
DateTimeFormatter ff =
    DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");

String str = "2026-03-31 15:47:40";

LocalDateTime t = LocalDateTime.parse(str, ff);

System.out.println(t);
```

**날짜를 문자열로 변환**

```java
String result = now.format(ff);

System.out.println(result);
```

**주요 패턴**

| MM | 월 |
| dd | 일 |
| HH | 24시간제 |
| hh | 12시간제 |

| ss | 초 |
