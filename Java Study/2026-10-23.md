## 1. 기본 문법 및 데이터형 정리


🔹 데이터형 분류

• 기본형 (Primitive Type): 실제 값을 stack 메모리에 저장합니다.
	• 정수형: byte (파일 입출력 시 활용), int, long
	• 실수형: float (AI/백터 연산 시 주로 활용), double
	• 논리형: boolean
	• 문자형: char (단일 문자, 최근에는 String으로 대체하여 주로 사용)
• 참조형 (Reference Type): 데이터가 저장된 Heap 영역의 메모리 주소를 저장합니다.
	• 배열, 클래스(인터페이스, 라이브러리, 사용자 정의 클래스)

🔹 연산자 및 제어문

• 연산자: 단항(++, --, !, 형변환), 이항(산술, 비교, 논리, 대입), 삼항 연산자(조건 ? 값 : 값)
• 제어문: 조건문(if, if~else), 선택문(switch~case), 반복문(for, while), 반복제어(break)

## 2. 자바 메모리 구조 (Java Memory Area)

자바 애플리케이션이 실행될 때 데이터는 성격에 따라 다음 3가지 영역으로 나뉘어 관리됩니다.
• Method Area (클래스 영역): 메소드의 바이트코드, static 변수 등이 저장되는 공간입니다.
• Stack Area (스택 영역): 메소드 내에서 선언된 지역 변수가 저장되며, {} 블록을 벗어나면 자동으로 메모리가 해제됩니다.
• Heap Area (힙 영역): new 키워드로 생성된 참조형 변수(객체, 배열 등)의 실제 데이터가 저장됩니다. 더 이상 참조되지 않는 데이터는 가비지 컬렉터(GC)가 수거합니다.

## 3. 알고리즘: 정렬 (Sorting)


🔹 버블 정렬 (Bubble Sort)

• 개념: 인접한 두 수를 비교하여 큰 수를 뒤로 보내는 정렬 방식입니다. 1회전(Round)이 끝날 때마다 가장 큰 수가 맨 뒤로 고정됩니다.

• 구현 예시 (오름차순):

for(int i = 0; i < arr.length - 1; i++) {
    for(int j = 0; j < arr.length - 1 - i; j++) {
        if(arr[j] > arr[j+1]) {
            int temp = arr[j];
            arr[j] = arr[j+1];
            arr[j+1] = temp;
        }
    }
}

🔹 선택 정렬 (Selection Sort)

• 개념: 기준 위치(i)를 정한 후, 그다음 위치(j)부터 끝까지 비교하며 가장 작은(또는 큰) 값을 찾아 정렬하는 방식입니다.
• 구현 예시 (내림차순 - char 배열):
for(int i = 0; i < arr.length - 1; i++) {
    for(int j = i + 1; j < arr.length; j++) {
        if(arr[i] < arr[j]) { // 부호 변경으로 오름/내림차순 조절
            char temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
        }
    }
}

## 4. 핵심 클래스: String (문자열 제어)

String은 내부적으로 char[]을 제어하는 래퍼 클래스로, final 클래스이므로 한 번 생성된 문자열은 변경이 불가능합니다(리터럴 재할당 시 새 주소 생성).

**🛠️ 자주 쓰는 핵심 메소드 요약**

• 데이터 추출 및 확인
	• charAt(int index): 지정한 인덱스의 문자 반환
	• length(): 문자열의 길이(글자 수) 반환
	• indexOf(String s) / lastIndexOf(String s): 특정 문자의 위치를 앞에서부터/뒤에서부터 찾아 인덱스 반환 (없으면 -1)

• 문자열 비교
	• equals(String s): 문자열 값 자체를 비교 (대소문자 구분)
	• equalsIgnoreCase(String s): 대소문자 구분 없이 문자열 값 비교

• 검색 및 조건
	• contains(String s): 특정 문자열이 포함되어 있는지 확인
	• startsWith(String s) / endsWith(String s): 특정 문자열로 시작/끝나는지 확인

• 변환 및 분리
	• replace(String target, String replacement): 문자열 변경
	• replaceAll(String regex, String replacement): 정규표현식을 이용한 문자열 변경 (ex: [^가-힣]을 사용해 한글만 남기기)
	• substring(int start, int end): 지정한 인덱스 범위만큼 문자열을 자름
	• split(String regex): 구분자를 기준으로 문자열을 잘라 배열로 반환
	• trim() / strip(): 문자열 좌우의 공백 제거
	• String.valueOf(Object data): 모든 기본형 및 데이터형을 문자열로 변환

## 5. 핵심 클래스: Enum (열거형)

• 개념: 연관된 상수들을 안전하고 편리하게 관리할 수 있도록 도와주는 클래스의 일종입니다.
• 속성을 가진 Enum 구현 예시 (지역별 전화국번 데이터 관리):

enum 전화국번 {
    서울("02"), 경기("031"), 인천("032"), 강원("033");

    private String code;
    전화국번(String code) { this.code = code; }
    public String getCode() { return code; }
}

AI

인공지능(AI, Artificial Intelligence)은 인간의 학습, 추론, 지각, 판단, 언어 이해 등 지적 능력을 컴퓨터 프로그램과 기계로 구현한 기술입니다. 백만 개의 규칙을 직접 코딩하는 대신, 백만 개의 데이터 예시를 보여주며 컴퓨터가 스스로 패턴을 학습하게 만드는 방식으로 작동합니다.
현재 AI 기술은 발전 단계와 기술적 특성에 따라 크게 다음과 같이 분류할 수 있습니다.

🤖 발전 단계에 따른 분류

• 약인공지능 (Weak AI / Narrow AI): 특정 조건이나 한정된 범위의 태스크만 수행할 수 있는 AI입니다. 우리가 일상에서 쓰는 Google 지도의 내비게이션, 스팸 필터, 스마트폰의 Gemini 같은 가상 비서가 모두 여기에 해당합니다.
• 강인공지능 (Strong AI / AGI): 인간과 동등한 수준의 지적 능력을 갖추어, 처음 접하는 환경이나 문제도 스스로 이해하고 해결할 수 있는 인공 일반 지능입니다.
• 초지능 (Superintelligence): 모든 영역에서 인간의 가장 뛰어난 지성을 훨씬 뛰어넘는 가상의 AI 단계입니다.

• 속성을 가진 Enum 구현 예시 (지역별 전화국번 데이터 관리):java
enum 전화국번 {
    서울("02"), 경기("031"), 인천("032"), 강원("033");

    private String code;
    전화국번(String code) { this.code = code; }
    public String getCode() { return code; }
}

## 6. 실전 활용 예제 (웹 크롤링 & 파일 데이터 처리)


🕵️ 1) Jsoup 라이브러리를 활용한 웹 음원 차트 검색

외부 라이브러리인 Jsoup을 이용해 특정 웹 페이지에 연결한 뒤, String 클래스의 contains 또는 endsWith 기능을 결합해 원하는 가수나 제목을 매칭하여 출력할 수 있습니다.
Document doc = Jsoup.connect("https://genie.co.kr").get();	
Elements title = doc.select("table.list-wrap a.title");
Elements singer = doc.select("table.list-wrap a.artist");

for(int j = 0; j < title.size(); j++) {
    if(title.get(j).text().contains(fd)) { // fd = 검색어
        System.out.println(title.get(j).text() + " (" + singer.get(j).text() + ")");
    }
}

📂 2) 파일 데이터(movie.txt) 파싱 및 조건 검색

FileReader와 StringBuffer를 이용해 대용량 텍스트 파일을 읽어온 후, 파이프라인(|) 기호로 구분된 데이터를 배열에 분할 수집하고 검색 시스템을 구축한 예제입니다.
// 파일 읽기 및 배열 저장 과정
String[] movies = sb.toString().split("\n");
for(String movie : movies) {
    String[] total = movie.split("\\|"); // 정규식 기호이므로 역슬래시(\\) 필수
    title[i] = total[1];
    actor[i] = total[4];
    // ... 각각의 배열에 분할 저장
}

// 조건문 기반의 특정 배우 출연작 검색 기능
for(int j = 0; j < actor.length; j++) {
    if(actor[j].contains(ac)) { // ac = 검색할 배우 이름
        System.out.println(title[j]);
    }
}
