## 2. 정렬 알고리즘

정렬은 여러 데이터를 일정한 기준에 따라 순서대로 배치하는 작업입니다.

- **오름차순(ASC):** 작은 값부터 큰 값 순서
- **내림차순(DESC):** 큰 값부터 작은 값 순서

### 2.1 버블 정렬(Bubble Sort)

인접한 두 원소를 비교하고 순서가 잘못되었다면 교환합니다. 한 회전이 끝나면 가장 큰 값이 배열의 마지막 쪽에 고정됩니다.

예시:

```text
초기 배열: 30 20 50 10 40
1회전:     20 30 10 40 50
2회전:     20 10 30 40 50
3회전:     10 20 30 40 50
```

코드:

```java
for (int i = 0; i < arr.length - 1; i++) {
    for (int j = 0; j < arr.length - 1 - i; j++) {
        if (arr[j] > arr[j + 1]) {
            int temp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = temp;
        }
    }
}
```

핵심:
- `arr[j]`와 `arr[j + 1]`을 비교합니다.
- 앞의 값이 더 크면 두 값을 교환합니다.
- 회전이 끝날 때마다 뒤쪽의 큰 값이 하나씩 확정됩니다.
- 일반적인 시간 복잡도는 평균·최악의 경우 `O(n²)`입니다.

### 2.2 선택 정렬 형태의 비교 정렬

수업 코드에서는 바깥쪽 인덱스 `i`와 뒤쪽 원소 `j`를 비교해 조건에 맞으면 즉시 교환합니다.

```java
for (int i = 0; i < arr.length - 1; i++) {
    for (int j = i + 1; j < arr.length; j++) {
        if (arr[i] > arr[j]) {
            int temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;
        }
    }
}
```

- 오름차순: `arr[i] > arr[j]`일 때 교환
- 내림차순: `arr[i] < arr[j]`일 때 교환
- 이 코드는 최솟값의 위치를 찾은 뒤 한 번 교환하는 전형적인 선택 정렬과는 다릅니다.
- 시간 복잡도는 `O(n²)`입니다.

### 2.3 Arrays.sort()

자바 표준 라이브러리가 제공하는 배열 정렬 메소드입니다.

```java
import java.util.Arrays;

int[] arr = {30, 20, 50, 10, 40};

System.out.println("정렬 전: " + Arrays.toString(arr));
Arrays.sort(arr);
System.out.println("정렬 후: " + Arrays.toString(arr));
```

알고리즘 원리를 학습할 때는 직접 구현하고, 실제 개발에서는 표준 라이브러리를 우선 고려합니다.

## 3. 열거형(enum)

`enum`은 정해진 상수 집합을 표현하는 자료형입니다. 요일, 상태, 지역 코드처럼 선택 가능한 값이 제한된 경우에 유용합니다.

### 기본 예제

```java
enum Day {
    월요일, 화요일, 수요일, 목요일, 금요일, 토요일, 일요일
}

public class EnumExample {
    public static void main(String[] args) {
        Day today = Day.금요일;

        System.out.println(today);
        System.out.println(today == Day.월요일);
    }
}
```

- `Day.금요일`: 열거형 상수
- `values()`: 모든 상수를 배열로 반환
- `name()`: 상수의 이름을 문자열로 반환
- `==`: 열거형 상수 비교에 사용 가능

### 생성자와 필드가 있는 enum

```java
enum 전화국번 {
    서울("02"),
    경기("031"),
    인천("032"),
    부산("051");

    private final String code;

    전화국번(String code) {
        this.code = code;
    }

    public String getCode() {
        return code;
    }
}
```

사용 예:

```java
for (전화국번 region : 전화국번.values()) {
    System.out.println(region.name() + ": " + region.getCode());
}
```

enum 생성자는 일반적으로 외부에서 직접 호출할 수 없으며, 각 상수를 선언할 때 실행됩니다.

### 주요 데이터형

|---|---|---|

| 문자열 | `String` | 문자열 |

### 연산자
- 산술: `+`, `-`, `*`, `/`, `%`
- 비교: `==`, `!=`, `<`, `>`, `<=`, `>=`

- 대입: `=`, `+=`, `-=`

### 제어문
- 조건문: `if`, `if-else`, `switch`
- 반복문: `for`, `while`, 향상된 `for`
- 반복 제어: `break`, `continue`

### 중첩 반복문으로 문자 출력

```java
for (int i = 1; i <= 4; i++) {

    System.out.println();
}
```

출력:

```text
ABCD

ABCD
ABCD
```

`char c = 'A';`가 바깥쪽 반복문 안에 있으므로 각 행마다 A부터 시작합니다.

## 5. 문자열(String)

`String`은 문자열을 다루는 클래스입니다. 길이 확인, 비교, 검색, 치환, 분리 등의 메소드를 제공합니다.

### 5.1 문자열 비교와 검색

| 메소드 | 의미 |
|---|---|
| `equals()` | 대소문자를 구분해 내용 비교 |
| `equalsIgnoreCase()` | 대소문자를 구분하지 않고 내용 비교 |
| `length()` | 문자열 길이 |
| `contains()` | 특정 문자열 포함 여부 |
| `startsWith()` | 특정 문자열로 시작하는지 확인 |
| `endsWith()` | 특정 문자열로 끝나는지 확인 |
| `indexOf()` | 처음 등장하는 위치 반환 |
| `lastIndexOf()` | 마지막 등장 위치 반환 |
| `charAt()` | 지정한 인덱스의 문자 반환 |

문자열 인덱스는 0부터 시작합니다. `indexOf()`는 검색 대상이 없으면 `-1`을 반환합니다.

**중요:** 문자열 내용 비교에는 `==` 대신 일반적으로 `equals()`를 사용합니다. `==`는 참조가 같은지를 비교합니다.

로그인 문법 예제:

```java
if (id.equalsIgnoreCase(myId) && pwd.equals(myPwd)) {
    System.out.println("로그인되었습니다");
} else {
    System.out.println("아이디나 비밀번호가 틀립니다");
}
```

이 코드는 문법 학습용입니다. 실제 서비스에서는 비밀번호를 코드에 하드코딩하지 않아야 합니다.

### 5.2 대소문자 변환과 치환

```java
String msg = "Hello Java!!";

System.out.println(msg.toUpperCase());
System.out.println(msg.toLowerCase());
System.out.println(msg.replace('a', 'b'));
System.out.println(msg.replace("Java", "Oracle"));
```

- `toUpperCase()`: 대문자로 변환
- `toLowerCase()`: 소문자로 변환
- `replace()`: 문자 또는 문자열 치환
- `replaceAll()`: 정규식을 사용한 치환

String은 불변 객체이므로 반환값을 다시 대입해야 변경 결과를 유지할 수 있습니다.

```java
msg = msg.replace("Java", "Oracle");
```

정규식 예제:

```java
String s = "ABCD가나다라12345";

System.out.println(s.replaceAll("[가-힣]", "0"));
System.out.println(s.replaceAll("[A-Z]", " "));
System.out.println(s.replaceAll("[0-9]", " "));
System.out.println(s.replaceAll("[^가-힣]", " "));
```

- `[가-힣]`: 한글 음절
- `[A-Z]`: 영문 대문자
- `[0-9]`: 숫자
- `[^가-힣]`: 한글이 아닌 문자

### 5.3 substring(), indexOf()

```java
String msg = "서울시 마포구";

System.out.println(msg.substring(4));
System.out.println(msg.substring(0, 4));
System.out.println(msg.substring(4, 7));
```

- `substring(start)`: start 인덱스부터 끝까지
- `substring(start, end)`: start부터 end - 1까지

파일 확장자 추출:

```java
String fileName = "자바.java";
String extension =
    fileName.substring(fileName.lastIndexOf(".") + 1);

System.out.println(extension); // java
```

### 5.4 trim(), valueOf(), join(), format()

```java
String msg = " Hello Java ";
System.out.println(msg.trim());

int a = 100;
int b = 200;

System.out.println(a + b);                // 300
System.out.println(String.valueOf(a) + b); // 100200

char[] chars = {'홍', '길', '동'};
System.out.println(String.valueOf(chars)); // 홍길동

String date = String.join("/", "2026", "10", "21");
System.out.println(date); // 2026/10/21

String result = String.format("%d %d %.2f", 90, 80, 85 / 3.0);
System.out.println(result);
```

- `trim()`: 양끝 공백 제거
- `strip()`: 유니코드 공백을 고려해 양끝 공백 제거(Java 11 이상)
- `String.valueOf()`: 값을 문자열로 변환
- `String.join()`: 구분자를 사용해 문자열 결합
- `String.format()`: 지정한 형식으로 문자열 생성
- `%d`: 정수, `%f`: 실수, `%.2f`: 소수점 둘째 자리까지

### 5.5 split()으로 문자열 나누기

```java
String msg = "홍길동|이순신|심청이|박문수|강감찬";
String[] names = msg.split("\\|");

for (String name : names) {
    System.out.println(name);
}
```

`split()`은 정규식을 기준으로 문자열을 나눕니다. `|`는 정규식의 특수문자이므로 문자 그대로 구분자로 사용하려면 `"\\|"`처럼 이스케이프해야 합니다.

## 6. 문자열 배열과 검색

### 6.1 향상된 for문

```java
String[] names = {"홍길동", "이순신", "심청이", "박문수", "강감찬"};

for (String name : names) {
    System.out.println(name);
}
```

배열의 모든 원소를 순서대로 읽을 때 유용합니다. 인덱스가 필요한 경우에는 일반 for문을 사용합니다.

### 6.2 최장·최단 문자열 찾기

데이터에서 영어 과일명 부분을 추출하고 문자열 길이를 비교합니다.

```java
String[] fruits = {
    "Apple-사과",
    "Banana-바나나",
    "Watermelon-수박"
};

int max = 0;

for (String fruit : fruits) {
    String name = fruit.substring(0, fruit.indexOf("-"));

    if (name.length() > max) {
        max = name.length();
    }
}

for (String fruit : fruits) {
    String name = fruit.substring(0, fruit.indexOf("-"));

    if (name.length() == max) {
        System.out.println(name);
    }
}
```

최장 또는 최단 이름이 여러 개라면 조건에 맞는 항목을 모두 출력할 수 있습니다. 최단값을 찾을 때는 `Integer.MAX_VALUE`를 사용하거나 첫 원소를 기준으로 초기화하면 안전합니다.

### 6.3 검색과 자동 완성

포함 검색:

```java
String keyword = "app";

for (String fruit : fruits) {
    if (fruit.toLowerCase().contains(keyword.toLowerCase())) {
        System.out.println(fruit);
    }
}
```

접두어 검색:

```java
if (fruit.toLowerCase().startsWith(keyword.toLowerCase())) {
    System.out.println(fruit);
}
```

- `contains()`: 문자열 중간을 포함해 검색
- `startsWith()`: 검색어로 시작하는 데이터 검색
- `endsWith()`: 특정 문자열로 끝나는 데이터 검색
- `toLowerCase()`: 대소문자를 통일해 비교

`Thread.sleep(1000)`은 실행을 1초 멈춥니다. 시연에는 사용할 수 있지만 검색 성능을 높이는 기능은 아닙니다.

## 7. 파일 입출력과 영화 데이터 처리

수업 예제에서는 `movie.txt` 파일을 읽고 각 줄을 `|` 구분자로 분리해 영화 정보를 추출합니다.

### 데이터 처리 순서

1. `FileReader`로 파일을 엽니다.
2. 파일 끝(`-1`)까지 문자를 읽습니다.
3. `StringBuffer`에 내용을 누적합니다.
4. 줄바꿈 기준으로 영화별 데이터를 나눕니다.
5. 각 영화 정보를 `|` 기준으로 분리합니다.
6. 제목, 장르, 출연진, 관람 등급, 감독 등을 검색합니다.

예시 데이터:

```text
1|쇼생크 탈출|드라마|포스터URL|팀 로빈스, 모건 프리먼|개봉일|15세 관람가|프랭크 다라본트
```

간단한 처리 예:

```java
String[] movies = fileContents.split("\\R");

for (String movie : movies) {
    String[] fields = movie.split("\\|", -1);

    if (fields.length >= 8) {
        String rank = fields[0];
        String title = fields[1];
        String genre = fields[2];
        String actors = fields[4];
        String grade = fields[6];
        String director = fields[7];

        System.out.println(rank + ". " + title);
    }
}
```

`split("\\|", -1)`은 마지막에 비어 있는 필드가 있어도 유지합니다. 필드 개수와 데이터 형식을 검증하는 것이 좋습니다.

### 검색 실습 아이디어

- 영화 제목으로 검색
- 관람 등급별 영화 검색
- 배우 이름으로 출연작 검색
- 감독 이름으로 작품 검색
- 페이지 번호로 10개씩 목록 출력
- 검색 결과 개수 계산

페이지 계산 예:

```java
int pageSize = 10;
int totalPages = (int) Math.ceil(movieCount / (double) pageSize);
int start = (page - 1) * pageSize;
int end = Math.min(start + pageSize, movieCount);

for (int i = start; i < end; i++) {
    System.out.println(movies[i]);
}
```

실제 코드에서는 페이지 번호가 유효한지 확인하고, 배열의 전체 길이가 아닌 실제 영화 데이터 개수를 기준으로 계산해야 합니다.

## 8. 웹 크롤링 기초(Jsoup)

Jsoup으로 웹 페이지 HTML을 가져와 CSS 선택자로 노래 제목과 가수명을 추출합니다.

```java
Document doc = Jsoup.connect(url).get();

Elements titles = doc.select("table.list-wrap a.title");
Elements singers = doc.select("table.list-wrap a.artist");
```

- `Jsoup.connect(url).get()`: 웹 페이지 요청
- `doc.select(cssSelector)`: CSS 선택자로 요소 검색
- `element.text()`: 요소의 텍스트 추출
- `Elements`: 검색된 요소 모음

검색어에 따라 제목 필터링:

```java
if (titles.get(j).text().contains(keyword)) {
    System.out.println(titles.get(j).text());
}
```

주의사항:
- 사이트 HTML 구조가 바뀌면 CSS 선택자도 수정해야 합니다.
- 네트워크 오류와 요청 실패를 처리해야 합니다.
- 사이트 이용약관, robots.txt, 저작권 및 접근 정책을 준수합니다.
- 제목과 가수 요소의 개수가 같다고 가정하지 말고 인덱스 범위를 확인합니다.
- 날짜가 URL에 고정되어 있으면 해당 날짜 데이터만 조회할 수 있습니다.

## 9. 메모리 구조와 참조형

- **스택(Stack):** 메소드 호출과 지역 변수 등에 사용되는 영역
- **힙(Heap):** 객체와 배열 등이 생성되는 영역
- **메소드 영역(Method Area):** 클래스 메타데이터, 런타임 상수 풀, 메소드 관련 정보 등이 저장되는 영역
- **가비지 컬렉터(GC):** 더 이상 도달할 수 없는 객체의 메모리를 회수

참조형 변수는 객체 자체가 아니라 객체를 참조하는 값을 가집니다. 실제 JVM의 세부 메모리 배치는 단순화된 그림과 다를 수 있습니다.

### 문자열 리터럴과 new String()

```java
String s1 = "Java";
String s2 = "Java";
String s3 = new String("Java");

System.out.println(s1.equals(s2)); // true
System.out.println(s1 == s2);      // 일반적인 리터럴 예제에서는 true
System.out.println(s1.equals(s3)); // true
System.out.println(s1 == s3);      // false
```

- `equals()`: 문자열 내용 비교
- `==`: 참조 비교
- 문자열 리터럴은 문자열 풀(String Pool)을 통해 재사용될 수 있습니다.
- `new String("Java")`는 별도의 String 객체를 만듭니다. 특별한 이유가 없다면 문자열 리터럴을 사용하는 편이 일반적입니다.

## 11. 주의사항 및 개선점

1. **정렬 알고리즘 구분:** 버블 정렬은 인접 원소를 비교합니다. 수업의 선택 정렬 코드는 비교할 때마다 교환하는 방식이므로 전형적인 선택 정렬과 구분합니다.
2. **실제 데이터 개수:** 고정 크기 배열의 미사용 `null` 요소가 검색에 포함되지 않도록 실제 데이터 개수를 관리합니다.
3. **파일 읽기:** `Files.readString()` 또는 `BufferedReader`를 고려하고 문자 인코딩을 명시합니다.
4. **자원 관리:** 파일 등은 필요에 따라 try-with-resources로 관리합니다.
5. **예외 처리:** 예상 가능한 예외를 구분하고 오류 원인을 기록합니다.
6. **문자열 비교:** 문자열 내용은 `equals()` 계열로 비교합니다.
7. **정규식:** `split()`과 `replaceAll()`은 정규식을 사용하므로 특수문자에 주의합니다.
8. **민감 정보:** 로그인 예제의 비밀번호는 학습용으로만 사용합니다.
9. **웹 크롤링:** 대상 사이트의 정책과 요청 제한을 확인합니다.
10. **문자열 불변성:** 문자열 변경 메소드의 반환값을 변수에 대입해야 합니다.
