## 1. 클래스의 구성 요소

클래스는 데이터와 기능을 묶어 객체를 생성하기 위한 설계도다.

```java
class Student {
    // 인스턴스 변수
    int hakbun;
    String name;

    // static 변수
    static String schoolName;

    // 생성자
    Student() {
        hakbun = 0;
        name = "미정";
    }

    // 메서드
    void display() {
        System.out.println(name);
    }
}
```

- **변수**: 데이터를 저장한다.
- **생성자**: 객체가 생성될 때 초기화 작업을 수행한다.
- **메서드**: 객체나 클래스가 수행할 기능을 정의한다.

### 변수와 메서드의 종류

| 구분 | 특징 | 사용 예시 |
|---|---|---|
| 인스턴스 변수 | 객체마다 별도로 존재 | `student.name` |
| static 변수 | 클래스와 연결되어 공유 | `Student.schoolName` |
| 인스턴스 메서드 | 객체를 통해 호출 | `student.display()` |
| static 메서드 | 객체 없이 클래스 이름으로 호출 가능 | `Student.show()` |

## 2. 객체 생성과 메모리 구조

### 객체 생성

```java
Student s1 = new Student();
Student s2 = new Student();
```

- `Student`: 클래스이자 참조 변수의 타입
- `s1`, `s2`: 객체를 참조하는 지역 변수
- `new Student()`: 새로운 객체를 생성하고 생성자를 호출
- 두 객체의 인스턴스 변수는 서로 독립적이다.

### 주요 메모리 영역

| 영역 | 주요 역할 |
|---|---|
| Stack | 메서드 실행과 관련된 프레임, 지역 변수 및 매개변수 등 관리 |
| Heap | 객체와 배열이 생성되는 영역 |
| 클래스 메타데이터 영역 | 클래스 정보, 메서드 정보 등 관리 |

객체의 참조를 저장하는 지역 변수와 실제 객체는 구분해야 한다.

```java
Student s1 = new Student();
Student s2 = new Student();

s1.name = "홍길동";
s2.name = "심청이";
```

`s1`과 `s2`가 서로 다른 객체를 참조하므로 이름도 각각 저장된다.

### 객체의 생명주기

1. `new`를 이용해 객체 생성
2. 참조 변수를 통해 객체 사용
3. 객체를 더 이상 참조할 수 없으면 가비지 컬렉터(GC)의 회수 대상이 될 수 있음

```java
Student s1 = new Student();
s1 = null;
```

`null`을 대입하면 해당 참조 변수가 객체를 가리키지 않게 된다. 객체가 즉시 소멸한다는 뜻은 아니다.

`System.gc()`도 가비지 컬렉션을 요청할 뿐, 즉시 메모리를 회수한다고 보장하지 않는다.

### 지역 변수와 인스턴스 변수

```java
class A {
    int a = 5;

    void display() {
        int a = 10;

        System.out.println(a);
        System.out.println(this.a);
    }
}
```

출력 결과:

```text
10
5
```

지역 변수와 인스턴스 변수의 이름이 같으면 지역 변수가 우선한다.

- `a`: 지역 변수
- `this.a`: 현재 객체의 인스턴스 변수

## 3. 생성자와 초기화

생성자는 객체가 생성될 때 초기 상태를 설정하는 특별한 구성 요소다.

### 생성자의 특징

1. 클래스 이름과 생성자 이름이 같다.
2. 반환형을 작성하지 않는다. `void`도 사용하지 않는다.
3. 생성자를 여러 개 선언할 수 있다.
4. 생성자는 객체 생성 과정에서 호출된다.
5. 생성자를 하나도 작성하지 않으면 컴파일러가 기본 생성자를 제공한다.
6. 생성자를 직접 하나라도 작성하면 기본 생성자가 자동으로 추가되지 않는다.

### 기본 생성자

```java
class Student {
    int hakbun;
    String name;

    Student() {
        hakbun = 1;
        name = "홍길동";
    }
}
```

사용:

```java
Student s1 = new Student();
```

### 매개변수가 있는 생성자

```java
class Student {
    int hakbun;
    String name;

    Student(int hakbun, String name) {
        this.hakbun = hakbun;
        this.name = name;
    }
}
```

사용:

```java
Student s1 = new Student(1, "홍길동");
```

### 생성자 오버로딩

매개변수의 개수, 타입 또는 순서가 달라야 한다.

```java
class Sawon {
    int sabun;
    String name;
    String dept;

    Sawon() {
        sabun = 1;
        name = "홍길동";
        dept = "개발부";
    }

    Sawon(int sabun, String name) {
        this.sabun = sabun;
        this.name = name;
        this.dept = "미지정";
    }

    Sawon(String name, String dept) {
        this.name = name;
        this.dept = dept;
    }

    Sawon(int sabun, String name, String dept) {
        this.sabun = sabun;
        this.name = name;
        this.dept = dept;
    }
}
```

다음 두 생성자는 함께 선언할 수 없다.

```java
Sawon(int sabun, String name) { }
Sawon(int sabun, String dept) { }
```

두 생성자의 매개변수 타입과 순서가 모두 같기 때문이다. 매개변수의 이름은 오버로딩을 구분하는 기준이 아니다.

### this의 의미

```java
Student(int hakbun, String name) {
    this.hakbun = hakbun;
    this.name = name;
}
```

- `this.hakbun`: 현재 객체의 인스턴스 변수
- `hakbun`: 생성자에 전달된 매개변수

`this()`는 같은 클래스의 다른 생성자를 호출한다. 생성자 호출문은 첫 번째 문장에 위치해야 한다.

### 초기화 방식

**1. 명시적 초기화**

```java
int a = 100;
```

**2. 인스턴스 초기화 블록**

```java
{
    a = 200;
}
```

**3. static 초기화 블록**

```java
static {
    b = 300;
}
```

**4. 생성자**

```java
A() {
    a = 400;
}
```

일반적인 초기화 순서는 다음과 같다.

- 클래스 초기화 시: static 필드 초기화 및 static 초기화 블록
- 객체 생성 시: 인스턴스 필드 초기화 및 인스턴스 초기화 블록
- 생성자 본문 실행

각 초기화 단계에서 같은 종류의 초기화 코드는 작성된 순서가 중요하다.

static 초기화 블록에서는 특정 객체의 인스턴스 변수를 직접 사용할 수 없다.

## 4. 변수의 종류와 this·super

### 변수의 종류

| 변수 종류 | 선언 위치 | 특징 |
|---|---|---|
| 지역 변수 | 메서드·생성자·블록 내부 | 사용 전에 초기화해야 함 |
| 인스턴스 변수 | 클래스 내부, 메서드 바깥 | 객체마다 별도로 존재 |
| static 변수 | `static`을 붙인 클래스 필드 | 클래스와 연결되어 공유 |

인스턴스 변수와 static 변수에는 기본값이 적용된다.

| 자료형 | 기본값 |
|---|---|
| `int` | `0` |
| `double` | `0.0` |
| `boolean` | `false` |
| 참조형 | `null` |

지역 변수는 자동으로 기본값이 지정되지 않으므로 사용하기 전에 직접 초기화해야 한다.

### this와 super

- `this`: 현재 객체를 가리킨다.
- `super`: 상위 클래스 부분의 멤버나 생성자에 접근할 때 사용한다.
- `this()`: 같은 클래스의 다른 생성자를 호출한다.
- `super()`: 상위 클래스 생성자를 호출한다.

`this()`와 `super()`는 생성자에서 첫 번째 문장에 위치해야 한다.

### 상속 예제

```java
class A {
    int a, b, c, d, e, f;
}

class B extends A {
    int x;
}

B obj = new B();
```

`B` 객체는 상속받은 `A`의 멤버와 자신이 선언한 멤버를 함께 가진다.

`static` 메서드에서는 특정 객체를 가리키는 `this`나 `super`를 직접 사용할 수 없다.

## 5. 접근 지정어와 제어어

### 접근 지정어

| 지정어 | 접근 범위 |
|---|---|
| `public` | 어디서든 접근 가능(추가적인 모듈 제한은 별도) |
| `protected` | 같은 패키지 및 상속 관계에 따른 접근 |
| default | 같은 패키지 내부 |
| `private` | 선언된 클래스 내부 |

### 주요 제어어

- `static`: 클래스와 연결된 필드나 메서드 등을 선언한다.
- `final`: 변수 재대입, 메서드 오버라이딩, 클래스 상속 등을 제한하는 데 사용한다.
- `abstract`: 추상 클래스 또는 추상 메서드를 선언한다.

## 6. 객체지향의 주요 특성

### 캡슐화

데이터와 기능을 하나로 묶고 접근을 제어해 내부 상태를 보호한다.

```java
class Student {
    private String name;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}
```

- Getter: 값 읽기
- Setter: 값 변경

Lombok의 `@Getter`, `@Setter`, `@Data` 등을 이용하면 관련 메서드 작성을 줄일 수 있다.

### 상속

기존 클래스의 특성을 물려받아 재사용하고 확장한다.

```java
class A {
}

class B extends A {
}
```

- `A`: 상위 클래스
- `B`: 하위 클래스

### 다형성

같은 이름 또는 상위 타입의 참조를 이용해 서로 다른 동작을 표현할 수 있다.

**오버로딩(Overloading)**

매개변수 목록을 달리해 같은 이름의 메서드나 생성자를 여러 개 선언한다.

```java
void print(int a) {
}

void print(String a) {
}
```

**오버라이딩(Overriding)**

하위 클래스에서 상위 클래스의 인스턴스 메서드를 재정의한다.

```java
class A {
    void display() {
        System.out.println("A");
    }
}

class B extends A {
    @Override
    void display() {
        System.out.println("B");
    }
}
```

오버로딩과 오버라이딩은 서로 다른 개념이다.

## 7. 배열과 컬렉션으로 객체 관리하기

### 객체 배열

```java
Student[] students = new Student[3];

students[0] = new Student(1, "홍길동");
students[1] = new Student(2, "심청이");
```

`new Student[3]`은 Student 객체 세 개를 자동으로 만드는 것이 아니다. Student 객체의 참조를 저장할 배열 칸 세 개를 생성한다.

각 칸에 객체를 넣으려면 별도로 객체를 생성해 대입해야 한다.

### ArrayList

```java
import java.util.ArrayList;
import java.util.List;

List<Student> list = new ArrayList<>();

list.add(new Student(1, "홍길동"));

Student s = list.get(0);
```

- `List<Student>`: Student 객체를 담는 리스트
- `add()`: 요소 추가
- `get(0)`: 첫 번째 요소 가져오기
- 배열과 리스트의 인덱스는 `0`부터 시작한다.

다음처럼 제네릭 타입을 생략할 수도 있지만 권장하지 않는다.

```java
List list = new ArrayList<>();
list.add(new Student(1, "홍길동"));

Student s = (Student) list.get(0);
```

제네릭을 사용하면 타입 안정성을 높이고 불필요한 형 변환을 줄일 수 있다.

## 8. 예제 코드: Student 클래스

```java
class Student {
    int hakbun;
    String name;
    int kor, eng, math;

    static String schoolName;

    Student() {
        System.out.println("객체 생성 시 필요한 작업");
        System.out.println("this = " + this);
    }

    Student(int hakbun, String name,
            int kor, int eng, int math) {
        this.hakbun = hakbun;
        this.name = name;
        this.kor = kor;
        this.eng = eng;
        this.math = math;
    }
}
```

사용 예제:

```java
import java.util.ArrayList;
import java.util.List;

public class MainClass {
    public static void main(String[] args) {
        Student s1 = new Student(1, "홍길동", 90, 90, 90);
        Student s2 = new Student(2, "심청이", 70, 70, 70);
        Student s3 = new Student(3, "박문수", 80, 80, 80);

        Student[] students = {s1, s2, s3};

        for (Student s : students) {
            System.out.println("학번: " + s.hakbun);
            System.out.println("이름: " + s.name);
            System.out.println("국어: " + s.kor);
            System.out.println("영어: " + s.eng);
            System.out.println("수학: " + s.math);
        }

        List<Student> list = new ArrayList<>();
        list.add(s1);

        Student s = list.get(0);
        System.out.println(s.name);
    }
}
```

### 핵심 포인트

- `Student`는 학생 한 명의 데이터를 표현한다.
- `Student[]`는 학생 객체의 참조를 여러 개 저장한다.
- `List<Student>`는 Student 객체를 리스트 형태로 관리한다.
- `static String schoolName`은 모든 Student 객체가 공유하는 변수다.

## 9. 예제 코드: static 변수와 메서드

```java
class A {
    static int a = 10;
    int b = 100;

    static void display() {
        int a = 20;
        System.out.println(a + a);
    }

    void aaa() {
        a *= 100;
        b = 200;
    }
}
```

실행 예제:

```java
public class MainClass {
    public static void main(String[] args) {
        A.display();

        A aa = new A();
        A bb = new A();

        bb.a = 1000;

        System.out.println(A.a);
        System.out.println(aa.b);
        System.out.println(bb.b);
    }
}
```

출력 결과:

```text
40
1000
100
100
```

### 결과 해설

- `display()`의 지역 변수 `a`는 static 변수 `A.a`를 가린다.
- 따라서 `a + a`는 `20 + 20`이 되어 `40`이 출력된다.
- `a`는 static 변수이므로 모든 객체가 공유한다.
- `b`는 인스턴스 변수이므로 객체마다 별도로 존재한다.
- static 변수는 `bb.a`처럼 객체를 통해서도 접근할 수 있지만, `A.a`처럼 클래스 이름으로 접근하는 것이 좋다.
