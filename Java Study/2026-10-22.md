## 1. 배열(Array)의 기본 개념

### 1-1. 배열이란?

배열은 같은 데이터 타입의 여러 데이터를 하나의 변수명으로 관리하는 자료구조이다.

- 인덱스(Index)는 `0`부터 시작한다.
- 배열의 크기는 생성 시 결정된다.
- `length`로 배열의 크기를 확인할 수 있다.
- 반복문을 이용해 데이터를 쉽게 처리할 수 있다.
- 배열의 크기를 변경하려면 새로운 배열을 생성해야 한다.

### 1-2. 배열 선언

```java
int[] arr;   // 권장 방식
int arr[];   // 사용 가능
```

### 1-3. 데이터 타입별 배열

| 배열 타입 | 활용 예시 |
|---|---|
| `byte[]` | 파일 및 네트워크 데이터 |
| `int[]` | 가격, 점수, 정수 |
| `long[]` | 큰 범위의 정수 |
| `char[]` | 문자 |
| `double[]` | 평점, 평균 |
| `boolean[]` | 참·거짓, 상태 확인 |
| `String[]` | 영화 제목, 노래 제목 |
| `Food[]` | 음식 객체 |
| `Recipe[]` | 레시피 객체 |

### 1-4. 배열 초기화

```java
int[] arr = {10, 20, 30, 40, 50};
int[] numbers = new int[5];
```

`new int[5]`로 생성한 배열은 기본값인 `0`으로 초기화된다.

### 1-5. 배열 출력

일반 `for`문은 인덱스를 이용해 데이터를 수정하거나 특정 위치에 접근할 때 사용한다.

```java
int[] arr = {10, 20, 30};

for (int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}
```

`for-each`문은 데이터를 순서대로 읽을 때 편리하다.

```java
for (int value : arr) {
    System.out.println(value);
}
```

## 2. 배열 참조와 메모리 구조

### 2-1. 배열 참조 공유

```java
int[] a = {10, 20, 30};
int[] b = a;

b[0] = 100;

System.out.println(a[0]); // 100
System.out.println(b[0]); // 100
```

`b = a`는 배열 자체를 복사하는 것이 아니라 배열에 대한 참조를 복사한다.

따라서 `a`와 `b`는 같은 배열을 공유한다.

### 2-2. `clone()`을 이용한 복사

```java
int[] a = {10, 20, 30};
int[] c = a.clone();

c[0] = 200;

System.out.println(Arrays.toString(a)); // [10, 20, 30]
System.out.println(Arrays.toString(c)); // [200, 20, 30]
```

`clone()`은 새로운 배열을 생성하여 기존 배열의 요소를 복사한다.

단, 객체 배열에서는 배열 안의 객체까지 새로 복사하지 않는 얕은 복사이다.

### 2-3. 배열 출력 방법

```java
System.out.println(a);
System.out.println(Arrays.toString(a));
```

- `a`: 배열의 참조를 나타내는 문자열
- `Arrays.toString(a)`: 배열 요소를 읽기 쉬운 형태로 출력

## 3. 배열 복사

### 3-1. `Arrays.copyOf()`

기존 배열을 복사하여 지정한 크기의 새로운 배열을 생성한다.

```java
import java.util.Arrays;

int[] arr = {100, 200, 300};

int[] copy1 = Arrays.copyOf(arr, 2);
int[] copy2 = Arrays.copyOf(arr, 5);

System.out.println(Arrays.toString(copy1));
// [100, 200]

System.out.println(Arrays.toString(copy2));
// [100, 200, 300, 0, 0]
```

- 배열 크기를 줄이면 지정한 길이까지만 복사한다.
- 배열 크기를 늘리면 추가 공간은 기본값으로 채워진다.
- 원본 배열은 변경되지 않는다.

### 3-2. `System.arraycopy()`

배열의 특정 범위를 다른 배열의 지정된 위치로 복사한다.

```java
int[] arr = {10, 20, 30, 40, 50};
int[] target = new int[5];

System.arraycopy(arr, 4, target, 0, 1);

System.out.println(Arrays.toString(target));
// [50, 0, 0, 0, 0]
```

매개변수 순서:

```java
System.arraycopy(원본배열, 원본시작위치,
                 대상배열, 대상시작위치, 복사개수);
```

### 3-3. 배열 복사 비교

| 방법 | 특징 |
|---|---|
| `b = a` | 참조 공유 |
| `a.clone()` | 새로운 배열에 전체 요소 복사 |
| `Arrays.copyOf()` | 지정한 길이로 새 배열 생성 |
| `System.arraycopy()` | 지정한 범위 복사 |

## 4. 배열을 활용한 2진수 변환

### 핵심 원리

10진수 정수를 2로 나누면서 나머지를 배열에 저장하고, 저장된 나머지를 역순으로 출력한다.

예시: `10`을 2진수로 변환

```text
10 ÷ 2 = 5 ... 0
 5 ÷ 2 = 2 ... 1
 2 ÷ 2 = 1 ... 0
 1 ÷ 2 = 0 ... 1

결과: 1010
```

### 관련 코드

```java
int[] binary = new int[16];
int index = 0;

while (true) {
    binary[index] = input % 2;
    input /= 2;

    if (input == 0) {
        break;
    }

    index++;
}

for (int i = binary.length - 1; i >= 0; i--) {
    System.out.print(binary[i]);
}
```

주의사항:

- 위 코드는 양수 입력을 전제로 한다.
- `0`과 음수 입력은 별도로 처리해야 한다.
- 16비트 범위를 벗어나는 입력에 대한 검사가 필요하다.

## 5. 배열을 활용한 달력 출력

### 5-1. 달력 계산 원리

달력을 직접 구현하려면 다음 요소를 계산해야 한다.

1. 전년도까지의 총 일수
2. 윤년 여부
3. 전달까지의 총 일수
4. 해당 월의 첫 번째 요일
5. 해당 월의 마지막 날짜

### 5-2. 윤년 판별

```java
if ((year % 4 == 0 && year % 100 != 0)
        || year % 400 == 0) {
    lastday[1] = 29;
} else {
    lastday[1] = 28;
}
```

4로 나누어떨어지면서 100으로 나누어떨어지지 않거나, 400으로 나누어떨어지면 윤년이다.

### 5-3. 월별 마지막 날짜

```java
int[] lastday = {
    31, 28, 31, 30, 31, 30,
    31, 31, 30, 31, 30, 31
};
```

배열 인덱스가 `0`부터 시작하므로 1월은 `lastday[0]`, 2월은 `lastday[1]`이다.

### 5-4. `Calendar` 클래스 활용

```java
Calendar cal = Calendar.getInstance();

cal.set(Calendar.YEAR, year);
cal.set(Calendar.MONTH, month - 1);
cal.set(Calendar.DATE, 1);

int week = cal.get(Calendar.DAY_OF_WEEK) - 1;
int lastday = cal.getActualMaximum(Calendar.DATE);
```

- `DAY_OF_WEEK`: 요일을 구한다.
- `getActualMaximum(Calendar.DATE)`: 해당 월의 마지막 날짜를 구한다.
- `Calendar.MONTH`: 1월이 `0`이므로 입력한 월에서 `1`을 빼야 한다.

## 6. 숫자 야구 게임

### 게임 규칙

컴퓨터가 서로 다른 세 자리 숫자를 생성하고 사용자가 숫자를 맞히는 프로그램이다.

- **Strike(S):** 숫자와 위치가 모두 일치
- **Ball(B):** 숫자는 일치하지만 위치가 다름
- **3 Strike:** 정답이므로 종료

| 정답 | 입력 | 결과 |
|---|---|---|
| 123 | 235 | 0S - 2B |
| 123 | 135 | 1S - 1B |
| 123 | 123 | 3S - 종료 |

### 배열을 이용한 숫자 저장

```java
int[] com = new int[3];
```

세 자리 숫자를 배열에 저장하고 난수를 생성할 때 중복을 검사한다.

중복 검사 시 주의할 점:

```java
if (com[j] == com[i]) {
    // 중복 처리
}
```

현재 위치의 숫자와 이전에 생성한 숫자를 비교해야 한다. 중복이면 해당 위치의 숫자를 다시 생성하는 방식으로 구현한다.

## 7. 이중 for문

이중 `for`문은 반복문 안에 다른 반복문이 있는 구조이다.

- 바깥쪽 반복문: 행 또는 줄을 제어한다.
- 안쪽 반복문: 각 행에서 반복할 작업을 제어한다.

### 7-1. 사각형 출력

```java
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 5; j++) {
        System.out.print("*");
    }
    System.out.println();
}
```

출력:

```text
*****
*****
*****
*****
*****
```

### 7-2. 삼각형 출력

```java
for (int i = 1; i <= 4; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print("*");
    }
    System.out.println();
}
```

출력:

```text
*
**
***
****
```

핵심 조건은 `j <= i`이다.

### 7-3. 역삼각형 출력

```java
for (int i = 1; i <= 4; i++) {
    for (int j = 1; j <= 5 - i; j++) {
        System.out.print("*");
    }
    System.out.println();
}
```

출력:

```text
****
***
**
*
```

행이 증가할수록 출력하는 별표의 수가 줄어든다.

### 7-4. 별표와 빈 별표 출력

```java
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 5; j++) {
        if (j >= i) {
            System.out.print("★");
        } else {
            System.out.print("☆");
        }
    }
    System.out.println();
}
```

출력:

```text
★★★★★
☆★★★★
☆☆★★★
☆☆☆★★
☆☆☆☆★
```

## 8. 구구단 출력

### 코드

```java
for (int i = 1; i <= 9; i++) {
    for (int j = 2; j <= 9; j++) {
        System.out.printf(
            "%2d * %2d = %2d\t",
            j, i, j * i
        );
    }
    System.out.println();
}
```

### 핵심 원리

- 바깥쪽 `i`: 곱하는 수를 1부터 9까지 변경한다.
- 안쪽 `j`: 단을 2단부터 9단까지 변경한다.
- `j * i`: 곱셈 결과를 계산한다.
- `%2d`: 정수를 두 칸 너비로 출력한다.
- `\t`: 탭, `\n`: 줄바꿈

## 9. 성적 처리와 등수 계산

### 9-1. 성적 배열 선언

```java
int[] kor = new int[3];
int[] eng = new int[3];
int[] math = new int[3];

int[] total = new int[3];
double[] avg = new double[3];
char[] score = new char[3];
int[] rank = new int[3];
```

각 배열의 동일한 인덱스는 같은 학생의 데이터를 나타낸다.

### 9-2. 총점과 평균

```java
total[i] = kor[i] + eng[i] + math[i];
avg[i] = total[i] / 3.0;
```

`3.0`으로 나누면 실수 형태의 평균을 구할 수 있다.

### 9-3. 학점 계산

```java
switch (total[i] / 30) {
    case 10, 9 -> score[i] = 'A';
    case 8 -> score[i] = 'B';
    case 7 -> score[i] = 'C';
    case 6 -> score[i] = 'D';
    default -> score[i] = 'F';
}
```

300점 만점을 기준으로 총점에 따라 학점을 부여한다. 위 코드는 Java의 화살표 `switch` 문법을 사용한다.

### 9-4. 등수 계산

```java
for (int i = 0; i < 3; i++) {
    rank[i] = 1;

    for (int j = 0; j < 3; j++) {
        if (total[i] < total[j]) {
            rank[i]++;
        }
    }
}
```

자신보다 총점이 높은 학생이 있을 때마다 등수를 증가시킨다.

점수가 같으면 같은 등수가 부여된다.

### 9-5. 성적표 출력

```java
System.out.printf(
    "%-5d%-5d%-5d%-7d%-7.2f%5c%5d\n",
    kor[i], eng[i], math[i],
    total[i], avg[i], score[i], rank[i]
);
```

- `%-5d`: 정수 왼쪽 정렬
- `%-7.2f`: 소수점 둘째 자리까지 출력
- `%5c`: 문자 출력
- `%5d`: 정수 출력

## 10. break, continue, 레이블

### 10-1. `break`

현재 실행 중인 반복문을 종료한다.

```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        break;
    }
    System.out.println(i);
}
```

출력:

```text
1
2
```

### 10-2. `continue`

현재 반복의 나머지 코드를 건너뛰고 다음 반복으로 이동한다.

```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;
    }
    System.out.println(i);
}
```

출력:

```text
1
2
4
5
```

### 10-3. 레이블을 이용한 `break`

중첩 반복문에서 바깥쪽 반복문까지 종료할 수 있다.

```java
outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) {
            break outer;
        }
        System.out.println("i=" + i + ", j=" + j);
    }
}
```

출력:

```text
i=1, j=1
```

`break outer;`는 `outer`라는 레이블이 붙은 반복문을 종료한다.
