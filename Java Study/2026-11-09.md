## 1. 리플렉션이란?

Reflection(리플렉션)은 **실행 중인 프로그램에서 클래스의 정보를 읽고 조작할 수 있는 자바 기능**이다.

일반적으로 객체를 생성하고 메소드를 호출할 때는 클래스와 메소드 이름을 코드에 직접 작성한다.

하지만 리플렉션을 사용하면 실행 시점에 클래스 정보를 확인하고, 생성자·멤버변수·메소드를 동적으로 사용할 수 있다.

예를 들어 다음과 같은 작업이 가능하다.

- 클래스에 선언된 메소드 목록 확인
- 멤버변수(Field) 목록 확인
- 생성자(Constructor) 정보 확인
- 생성자를 이용한 객체 생성
- private 멤버변수 접근 및 값 변경
- 메소드 이름을 이용한 동적 메소드 호출

## 2. 자바의 실행 시점

자바 프로그램은 크게 컴파일 시점과 실행 시점으로 구분할 수 있다.

### ① 컴파일 시점

- `javac` 명령어를 통해 `.java` 파일을 `.class` 파일로 변환한다.
- 소스 코드의 문법과 자료형 등을 검사한다.
- 클래스와 메소드 등의 구조가 바이트코드로 변환된다.

### ② 실행 시점

- `java` 명령어를 통해 프로그램을 실행한다.
- JVM이 클래스 정보를 읽고 객체를 생성한다.
- 프로그램의 명령에 따라 메소드가 실행된다.
- 리플렉션을 이용하면 실행 중에 클래스의 구조를 확인하고 조작할 수 있다.

**핵심:** 리플렉션은 실행 시점에 클래스 정보를 동적으로 분석하고 활용하는 기술이다.

## 3. 클래스의 구조

자바 클래스는 크게 세 가지 구성 요소로 나눌 수 있다.

```java
class Member {
    // 멤버변수
    private int mno;
    private String name;

    // 생성자
    public Member() {
    }

    // 메소드
    public void insert() {
    }
}
```

| 구성 요소 | 리플렉션 클래스 | 설명 |
|---|---|---|
| 멤버변수 | Field | 클래스의 데이터 |
| 생성자 | Constructor | 객체 생성 담당 |
| 메소드 | Method | 객체의 기능 담당 |

## 4. 리플렉션 주요 클래스

리플렉션은 `java.lang.reflect` 패키지의 클래스를 중심으로 사용한다.

| 클래스 | 역할 |
|---|---|
| Class | 클래스의 전체 정보 확인 |
| Field | 멤버변수 정보 확인 및 조작 |
| Constructor | 생성자 정보 확인 및 객체 생성 |
| Method | 메소드 정보 확인 및 실행 |

## 5. Class 객체 얻기

리플렉션을 사용하려면 먼저 `Class` 객체를 얻어야 한다.

### 방법 1. 클래스명.class

```java
Class cls = String.class;
```

### 방법 2. 객체.getClass()

```java
String str = "";
Class cls = str.getClass();
```

### 방법 3. Class.forName()

```java
Class cls = Class.forName("java.lang.String");
```

특히 `Class.forName()`은 클래스 이름을 문자열로 전달하여 실행 시점에 클래스를 찾을 때 사용한다.

```java
Class cls = Class.forName("com.sist.reflect.Member");
```

## 6. 리플렉션의 주요 메소드

### ① 메소드 정보 확인

```java
Method[] methods = cls.getDeclaredMethods();

for (Method m : methods) {
    System.out.println(m.getName());
}
```

- `getDeclaredMethods()` : 해당 클래스에 선언된 모든 메소드 정보 반환
- `getName()` : 메소드 이름 반환

### ② 멤버변수 정보 확인

```java
Field[] fields = cls.getDeclaredFields();

for (Field f : fields) {
    System.out.println(f.getName());
}
```

- `getDeclaredFields()` : 해당 클래스에 선언된 모든 멤버변수 정보 반환
- `getName()` : 변수 이름 반환

### ③ 생성자 정보 확인

```java
Constructor[] constructors = cls.getDeclaredConstructors();

for (Constructor c : constructors) {
    System.out.println(c.getName());
}
```

- `getDeclaredConstructors()` : 해당 클래스에 선언된 생성자 정보 반환

### ④ 생성자를 이용한 객체 생성

```java
Object obj = cls
    .getDeclaredConstructor(int.class, String.class, String.class)
    .newInstance(2, "박문수", "부산");
```

일반적인 객체 생성 방식과 비교하면 다음과 같다.

```java
Member obj = new Member(2, "박문수", "부산");
```

리플렉션은 생성자에 필요한 자료형과 순서를 지정하여 실행 시점에 객체를 생성한다.

### ⑤ private 멤버변수 접근 및 수정

```java
Field f = cls.getDeclaredField("address");

f.setAccessible(true);
f.set(obj, "제주");

System.out.println(f.get(obj));
```

| 메소드 | 역할 |
|---|---|
| `getDeclaredField()` | 특정 멤버변수 정보 가져오기 |
| `setAccessible(true)` | 접근 제한을 우회할 수 있도록 설정 |
| `set(obj, 값)` | 객체의 멤버변수 값 변경 |
| `get(obj)` | 객체의 멤버변수 값 읽기 |

`private` 변수는 일반적인 방법으로 외부에서 접근할 수 없지만, 리플렉션을 이용하면 접근 제한을 우회할 수 있다. 단, 실행 환경의 모듈 및 보안 정책에 따라 제한될 수 있다.

### ⑥ 메소드 실행

```java
Method m = cls.getDeclaredMethod("insert");

m.invoke(obj);
```

- `getDeclaredMethod()` : 지정한 이름과 매개변수에 해당하는 메소드 정보 가져오기
- `invoke()` : 해당 객체를 대상으로 메소드 실행

메소드에 매개변수가 없다면 `invoke(obj)` 형태로 호출할 수 있다.

## 7. 리플렉션의 장점과 단점

### 장점

1. 실행 시점에 클래스 정보를 동적으로 확인할 수 있다.
2. 객체 생성과 메소드 호출을 자동화할 수 있다.
3. 공통 기능을 만들어 코드 재사용성을 높일 수 있다.
4. 다양한 프레임워크의 내부 동작에 활용된다.

### 단점

1. 일반적인 메소드 호출보다 성능 부담이 발생할 수 있다.
2. private 멤버에 접근할 수 있어 보안 및 캡슐화 문제가 발생할 수 있다.
3. 코드가 복잡해지고 가독성이 떨어질 수 있다.
4. 컴파일 시점에 확인하기 어려운 오류가 실행 시점에 발생할 수 있다.

## 8. 실습 코드

### Member.java

```java
package com.sist.reflect;

class Member {
    private int mno = 1;
    private String name = "홍길동";
    private String address = "서울";

    public Member() {
    }

    public Member(int mno, String name, String address) {
        this.mno = mno;
        this.name = name;
        this.address = address;
    }

    public void insert() {
        System.out.println("insert...");
    }

    public void update() {
        System.out.println("update...");
    }

    public void delete() {
        System.out.println("delete...");
    }

    public void select() {
        System.out.println("select...");
    }
}
```

### 리플렉션_2.java

```java
package com.sist.reflect;

import java.lang.reflect.Constructor;
import java.lang.reflect.Field;
import java.lang.reflect.Method;
import java.util.Scanner;

public class 리플렉션_2 {
    public static void main(String[] args) {

        try {
            // 1. 클래스 정보 가져오기
            Class cls = Class.forName("com.sist.reflect.Member");

            // 2. 메소드 정보 확인
            System.out.println("========= Method =========");

            Method[] methods = cls.getDeclaredMethods();

            for (Method m : methods) {
                System.out.println(m.getName());
            }

            // 3. 멤버변수 정보 확인
            System.out.println("========= 변수(멤버) =========");

            Field[] fields = cls.getDeclaredFields();

            for (Field f : fields) {
                System.out.println(f.getName());
            }

            // 4. 생성자 정보 확인
            System.out.println("========= 생성자 =========");

            Constructor[] con = cls.getDeclaredConstructors();

            for (Constructor c : con) {
                System.out.println(c.getName());
            }

            // 5. 생성자를 이용한 객체 생성
            System.out.println("========= 객체 메모리 할당 =========");

            Object obj = cls
                .getDeclaredConstructor(
                    int.class,
                    String.class,
                    String.class
                )
                .newInstance(2, "박문수", "부산");

            System.out.println("객체 주소:" + obj);

            // 6. private 멤버변수 변경

            Field f = cls.getDeclaredField("address");
            f.setAccessible(true);
            f.set(obj, "제주");
            System.out.println(f.get(obj));

            f = cls.getDeclaredField("name");
            f.setAccessible(true);
            f.set(obj, "심청이");
            System.out.println(f.get(obj));

            f = cls.getDeclaredField("mno");
            f.setAccessible(true);
            f.set(obj, 3);
            System.out.println(f.get(obj));

            // 7. 메소드 동적 실행
            System.out.println("======== 메소드 제어 ==========");

            Scanner scan = new Scanner(System.in);

            System.out.print("검색어 입력:");
            String fd = scan.next();

            for (Method m : methods) {
                if (fd.equals(m.getName())) {
                    m.invoke(obj);
                }
            }

            scan.close();

        } catch (Exception ex) {
            ex.printStackTrace();
        }
    }
}
```

## 9. 실행 결과 및 동작 원리

### ① 클래스 정보 확인

```text
========= Method =========
insert
update
delete
select

========= 변수(멤버) =========
mno
name
address

========= 생성자 =========
com.sist.reflect.Member
com.sist.reflect.Member
```

메소드와 필드, 생성자의 출력 순서는 JVM 구현에 따라 달라질 수 있다.

### ② 객체 생성 및 변수 변경

```text
========= 객체 메모리 할당 =========
객체 주소:com.sist.reflect.Member@...
제주
심청이
3
```

생성자를 통해 다음과 같은 객체가 만들어진다.

| 변수 | 생성 당시 값 | 변경 후 값 |
|---|---|---|
| mno | 2 | 3 |
| name | 박문수 | 심청이 |
| address | 부산 | 제주 |

`객체 주소`는 실제 메모리 주소가 아니라 기본 `toString()`이 출력하는 클래스명과 해시코드 표현이다.

### ③ 메소드 동적 실행

```text
======== 메소드 제어 ==========
검색어 입력:insert

insert...
```

사용자가 `insert`를 입력하면 다음 과정으로 실행된다.

1. `Scanner`로 사용자 입력을 받는다.
2. `getDeclaredMethods()`로 가져온 메소드 배열을 반복한다.
3. 입력값과 메소드 이름을 비교한다.
4. 이름이 일치하면 `invoke()`를 호출한다.
5. 해당 객체의 메소드가 실행된다.

예를 들어 다음과 같이 입력할 수 있다.

| 입력값 | 실행 결과 |
|---|---|
| insert | insert... |
| update | update... |
| delete | delete... |
| select | select... |

## 10. 실무 활용 사례

리플렉션은 다양한 자바 프레임워크의 내부 동작에 활용된다.

### ① Spring / Spring Boot

- 어노테이션을 분석하여 클래스와 메소드의 역할을 파악한다.
- `@GetMapping`, `@PostMapping` 등을 분석하여 HTTP 요청과 메소드를 연결한다.
- 객체 생성과 의존성 주입 과정에 활용한다.

### ② MyBatis

- 매핑 정보를 바탕으로 SQL 실행 결과를 객체에 연결한다.
- 객체의 멤버변수와 값을 분석하여 데이터를 처리한다.

### ③ JPA

- 엔티티의 필드 정보를 분석한다.
- 데이터베이스와 객체 사이의 매핑 및 데이터 처리에 활용한다.

**핵심 정리**

리플렉션은 클래스의 정보를 실행 시점에 읽고, 객체 생성·변수 접근·메소드 실행을 동적으로 처리하는 기술이다.

```text
Class
  |
  |-- getDeclaredMethods()
  |       └── Method 정보 확인
  |
  |-- getDeclaredFields()
  |       └── Field 정보 확인 및 값 변경
  |
  |-- getDeclaredConstructors()
  |       └── Constructor 정보 확인
  |               └── newInstance() 객체 생성
  |
  └-- getDeclaredMethod()
          └── invoke() 메소드 실행
```
