# 1. 중첩 클래스 (Nested Class)

## 1-1. 중첩 클래스란?

- 클래스 내부에 또 다른 클래스를 선언하는 방식
- 클래스 간의 관계를 명확하게 표현할 수 있다.
- 특정 클래스에서만 사용하는 클래스를 내부에 선언하여 코드의 복잡성을 줄일 수 있다.
- 외부 클래스와 내부 클래스가 데이터 및 메소드를 공유하기 편리하다.

```java
class Outer {
    class Inner {
        
    }
}
```

## 1-2. 중첩 클래스의 종류

| 종류 | 설명 |
|---|---|
| 멤버 클래스 | 외부 클래스의 멤버 위치에 선언하는 클래스 |
| 정적 멤버 클래스 | static 키워드를 사용하여 선언하는 클래스 |
| 지역 클래스 | 메소드 내부에 선언하는 클래스 |
| 익명 클래스 | 이름 없이 일회성으로 선언하는 클래스 |

# 2. 멤버 클래스 (Member Inner Class)

## 2-1. 개념

- 외부 클래스의 멤버 영역에 선언하는 내부 클래스
- 외부 클래스의 인스턴스 변수와 메소드에 접근할 수 있다.
- 외부 클래스의 객체를 먼저 생성한 다음 내부 클래스 객체를 생성해야 한다.

## 2-2. 기본 문법

```java
class Outer {
    private String name = "홍길동";

    class Inner {
        int a = 10;

        public void print() {
            System.out.println(a + ":" + name);
        }
    }
}
```

## 2-3. 객체 생성 방법

```java
Outer p = new Outer();
Outer.Inner c = p.new Inner();

c.print();
```

**실행 결과**

```text
10:홍길동
```

**핵심**

```java
Outer.Inner c = p.new Inner();
```

- 외부 클래스 객체를 먼저 생성한다.
- 외부 클래스 객체를 통해 내부 클래스 객체를 생성한다.
- 내부 클래스는 외부 클래스의 멤버에 접근할 수 있다.

# 3. 정적 멤버 클래스 (Static Nested Class)

## 3-1. 개념

- static 키워드를 사용하여 선언하는 내부 클래스
- 외부 클래스의 객체를 생성하지 않아도 내부 클래스 객체를 생성할 수 있다.
- 외부 클래스의 인스턴스 멤버에는 직접 접근할 수 없다.
- 외부 클래스의 정적 멤버에는 접근할 수 있다.

## 3-2. 기본 문법

```java
class Outer2 {
    static class Inner {
        public void print() {
            System.out.println("static Inner:print() Call...");
        }
    }
}
```

## 3-3. 객체 생성 방법

```java
Outer2.Inner c1 = new Outer2.Inner();

c1.print();
```

**실행 결과**

```text
static Inner:print() Call...
```

**핵심**

```java
Outer2.Inner c1 = new Outer2.Inner();
```

- 외부 클래스의 객체 생성이 필요 없다.
- 클래스 이름을 통해 직접 내부 클래스 객체를 생성한다.

# 4. 지역 클래스 (Local Inner Class)

## 4-1. 개념

- 메소드 내부에 클래스를 선언하는 방식
- 해당 메소드 내부에서만 사용할 수 있다.
- 메소드가 실행되는 동안에만 사용할 수 있다.
- 특정 메소드에서만 필요한 기능을 구현할 때 활용한다.

## 4-2. 기본 문법

```java
class Outer3 {

    public void print() {

        class Inner {
            public void print() {
                System.out.println(
                    "지역클래스:Inner:print() Call..."
                );
            }
        }

        Inner i = new Inner();
        i.print();
    }
}
```

## 4-3. 실행 방법

```java
Outer3 o = new Outer3();
o.print();
```

**실행 결과**

```text
지역클래스:Inner:print() Call...
```

**핵심**

- 지역 클래스는 선언된 메소드 내부에서만 사용 가능하다.
- 메소드 외부에서는 직접 객체를 생성할 수 없다.

# 5. 익명 클래스 (Anonymous Inner Class)

## 5-1. 개념

- 클래스 이름 없이 객체를 생성하면서 클래스를 정의하는 방식
- 별도의 상속 클래스를 만들지 않고 메소드를 재정의(Override)할 수 있다.
- 일회성으로 사용할 객체를 생성할 때 유용하다.
- 이벤트 처리, GUI, 콜백(Callback) 등에 활용된다.

## 5-2. 기본 개념

일반적인 상속 방식

```java
class A extends B {

    @Override
    public void display() {
        System.out.println("오버라이딩");
    }
}
```

익명 클래스 방식

```java
class A {

    B b = new B() {

        @Override
        public void display() {
            System.out.println("오버라이딩");
        }

    };
}
```

## 5-3. 실제 코드

```java
class Outer4 {

    Inner in = new Inner() {

        @Override
        public void print() {
            System.out.println(
                "Outer4에서 print() 오버라이딩됨"
            );
        }
    };
}
```

기본 클래스

```java
class Inner {

    public void print() {
        System.out.println("Inner:print() Call...");
    }
}
```

실행

```java
Inner i = new Inner();
i.print();

Outer4 o4 = new Outer4();
o4.in.print();
```

**실행 결과**

```text
Inner:print() Call...
Outer4에서 print() 오버라이딩됨
```

**핵심**

- 기존 클래스의 메소드를 익명 클래스 내부에서 재정의할 수 있다.
- 별도의 상속 클래스를 작성할 필요가 없다.
- 익명 클래스는 일회성 객체 생성에 적합하다.

# 6. 중첩 클래스의 this와 변수 접근

## 6-1. 개념

중첩 클래스 내부에서 동일한 이름의 변수가 존재할 경우 변수의 접근 범위를 구분해야 한다.

- 지역 변수: 메소드 내부에 선언된 변수
- 내부 클래스 변수: 내부 클래스에 선언된 변수
- 외부 클래스 변수: 외부 클래스에 선언된 변수

## 6-2. 기본 코드

```java
class Outer5 {

    int value = 10;

    public void display() {

        Inner i = new Inner();
        i.method();
    }

    class Inner {

        int value = 20;

        public void method() {

            int value = 30;

            System.out.println("value=" + value);
            System.out.println("value=" + this.value);
            System.out.println("value=" + Outer5.this.value);
        }
    }
}
```

## 6-3. 변수 접근 방법

```java
System.out.println("value=" + value);
```
- 가장 가까운 지역 변수에 접근한다.
- 결과: 30

```java
System.out.println("value=" + this.value);
```
- 현재 내부 클래스의 인스턴스 변수에 접근한다.
- 결과: 20

```java
System.out.println("value=" + Outer5.this.value);
```
- 외부 클래스의 인스턴스 변수에 접근한다.
- 결과: 10

**실행 결과**

```text
value=30
value=20
value=10
```

**핵심 정리**

| 표현식 | 접근 대상 | 값 |
|---|---|---|
| value | 지역 변수 | 30 |
| this.value | 내부 클래스 변수 | 20 |
| Outer5.this.value | 외부 클래스 변수 | 10 |

# 7. 중첩 클래스의 활용 - 스레드와 GUI

## 7-1. 활용 목적

중첩 클래스는 외부 클래스와 내부 클래스가 공통으로 사용하는 변수와 메소드가 있는 경우 유용하다.

대표적인 활용 분야

- GUI 프로그래밍
- 이벤트 처리
- 스레드(Thread)
- 서버와 클라이언트 통신

예를 들어 GUI 프로그램에서 버튼, 이미지, 화면 등의 요소를 외부 클래스에서 관리하고 내부 클래스에서 스레드를 실행할 수 있다.

## 7-2. GUI와 스레드의 관계

```java
class A extends JFrame {

    // 이미지, 버튼 등의 GUI 요소

    class Game extends Thread {

        @Override
        public void run() {
            // 스레드 실행
        }
    }
}
```

- 외부 클래스: GUI 화면 및 데이터 관리
- 내부 클래스: 스레드 실행
- 내부 클래스는 외부 클래스의 멤버를 공유하여 사용 가능

## 7-3. 서버와 클라이언트 구조

```java
class Server {

    List list = new ArrayList();
    int port = 3355;

    class Client extends Thread {

        @Override
        public void run() {
            // 클라이언트 통신 처리
        }
    }
}
```

- Server: 서버 정보 및 접속자 데이터 관리
- Client: 클라이언트별 통신 처리
- 서버와 클라이언트가 데이터를 공유하기 편리하다.

# 8. 익명 클래스를 활용한 JTable

## 8-1. 개념

JTable에서 특정 셀을 수정하지 못하도록 설정할 수 있다.

이때 DefaultTableModel을 익명 클래스로 생성하고 isCellEditable() 메소드를 오버라이딩한다.

## 8-2. 코드

```java
import javax.swing.*;
import java.awt.*;
import javax.swing.table.*;

public class 중첩클래스 extends JFrame {

    JTable table;
    DefaultTableModel model;

    public 중첩클래스() {

        String[] col = {"아이디", "이름", "성별"};
        String[][] row = new String[0][3];

        // 익명 클래스를 이용한 메소드 오버라이딩
        model = new DefaultTableModel(row, col) {

            @Override
            public boolean isCellEditable(int row, int column) {
                return false;
            }
        };

        table = new JTable(model);

        JScrollPane js = new JScrollPane(table);

        add("Center", js);

        setSize(350, 300);
        setVisible(true);

        String[] arr = {"admin", "홍길동", "남자"};
        model.addRow(arr);
    }

    public static void main(String[] args) {
        new 중첩클래스();
    }
}
```

## 8-3. 핵심 내용

```java
model = new DefaultTableModel(row, col) {

    @Override
    public boolean isCellEditable(int row, int column) {
        return false;
    }
};
```

- DefaultTableModel을 상속하는 익명 클래스를 생성한다.
- isCellEditable() 메소드를 오버라이딩한다.
- return false를 통해 모든 셀의 수정 기능을 비활성화한다.

# 9. 중첩 클래스의 장단점과 활용 분야

## 9-1. 장점

1. 다른 클래스와 연결하여 사용하기 쉽다.
2. 외부 클래스와 내부 클래스 간 데이터 및 메소드 공유가 편리하다.
3. 특정 클래스에서만 사용하는 클래스를 내부에 선언할 수 있다.
4. 코드의 복잡성을 줄이고 관련 기능을 하나의 클래스로 묶을 수 있다.

## 9-2. 단점

1. 객체 생성 방식이 일반 클래스보다 복잡할 수 있다.
2. 멤버 클래스는 외부 클래스 객체가 먼저 필요하다.
3. 클래스 간 결합도가 높아질 수 있다.

## 9-3. 객체 생성 방식 비교

일반 클래스

```java
A a = new A();
B b = new B();
```

멤버 클래스

```java
A a = new A();
A.B b = a.new B();
```

정적 멤버 클래스

```java
A.B b = new A.B();
```

## 9-4. 종류별 활용

| 종류 | 주요 활용 |
|---|---|
| 멤버 클래스 | GUI, 스레드, 서버와 클라이언트 |
| 정적 멤버 클래스 | 외부 객체와 독립적인 보조 클래스 |
| 지역 클래스 | 특정 메소드 내부의 제한적인 기능 |
| 익명 클래스 | 이벤트 처리, 메소드 오버라이딩, 콜백 |

# 10. 예외처리 (Exception Handling)

## 10-1. 예외처리란?

- 프로그램 실행 중 발생하는 예외 상황을 처리하는 기술
- 예외가 발생하더라도 프로그램이 비정상적으로 종료되는 것을 방지한다.
- 예외 발생 시 적절한 오류 메시지를 출력하거나 대체 작업을 수행할 수 있다.

## 10-2. 예외처리의 종류

예외처리는 크게 직접 처리와 예외 전달 방식으로 구분할 수 있다.

**① 직접 처리**

```java
try {
    // 예외가 발생할 수 있는 코드
}
catch(Exception e) {
    // 예외 처리
}
finally {
    // 예외 발생 여부와 관계없이 실행
}
```

- try: 예외가 발생할 가능성이 있는 코드 작성
- catch: 발생한 예외를 처리
- finally: 예외 발생 여부와 관계없이 실행되는 코드 작성
- finally는 생략 가능하다.

**② 예외 전달**

```java
public void method() throws IOException {

    // 예외가 발생할 수 있는 코드

}
```

- throws: 메소드에서 발생할 수 있는 예외를 호출한 곳으로 전달
- 호출한 메소드에서 예외를 처리하도록 할 수 있다.

## 10-3. try-catch-finally

```java
try {

    // 예외 발생 가능 코드

}
catch(Exception e) {

    // 예외 처리

}
finally {

    // 자원 해제 및 마무리 작업

}
```

## 10-4. finally의 활용

finally는 파일, 서버, 데이터베이스 등의 자원을 해제할 때 활용할 수 있다.

대표적인 자원 해제 작업

- 파일 닫기(close)
- 데이터베이스 연결 종료
- 서버 통신 자원 정리

단, 현대 Java에서는 try-with-resources를 활용하여 자원을 자동으로 해제하는 방식도 많이 사용한다.
