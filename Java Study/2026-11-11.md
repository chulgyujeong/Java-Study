## 3. ArrayList 주요 기능 및 CRUD

- 데이터 추가: `add()`
- 특정 위치 데이터 추가: `add(index, value)`
- 데이터 조회: `get()`
- 데이터 수정: `set()`
- 데이터 삭제: `remove()`
- 데이터 개수 확인: `size()`
- 전체 데이터 삭제: `clear()`
- 데이터 존재 여부 확인: `isEmpty()`

## 4. 컬렉션 데이터 처리 및 집합 연산

- 부분 데이터 추출: `subList()`
- 전체 데이터 복사: `addAll()`
- 공통 데이터 추출: `retainAll()`
- 데이터 포함 여부 확인: `containsAll()`
- 데이터 정렬: `Collections.sort()`
- UNION, INTERSECT, UNION ALL, MINUS 개념
- 여러 컬렉션 간 데이터 비교 및 관리

## 5. 제네릭(Generic)

- 제네릭의 개념과 필요성
- 데이터 타입 통일 및 안정성 확보
- 불필요한 형변환 방지
- 컴파일 단계에서 타입 오류 확인
- 제네릭 클래스 구현
  - `class Box<T>`
  - `Box<String>`
  - `Box<Integer>`
- 제네릭 타입의 종류
  - T(Type)
  - E(Element)
  - K(Key)
  - V(Value)
- 제한된 제네릭: `extends`
- 와일드카드: `<?>`
