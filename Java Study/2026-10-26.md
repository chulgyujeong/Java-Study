## 1. 메소드의 개념

메소드(Method)는 특정 작업을 수행하는 명령문들의 집합이다.

주요 목적:
- 반복되는 코드 제거
- 코드 재사용
- 가독성 향상
- 유지보수 편리
- 기능별 프로그램 구성

메소드는 클래스 내부에 선언한다. 메소드 안에 다른 메소드를 직접 선언할 수는 없다.

## 2. 메소드 선언과 호출

기본 형식:

```java
static 리턴형 메소드명(매개변수) {
    // 작업 처리
    return 반환값;
}
```

- 리턴형: 반환할 값의 자료형
- 메소드명: 기능을 나타내는 이름
- 매개변수: 메소드가 전달받는 입력값
- 구현부: 실제 작업을 수행하는 코드
- return: 결과를 반환하고 메소드 실행을 종료

예제:

```java
static int add(int a, int b) {
    return a + b;
}

public static void main(String[] args) {
    int result = add(10, 20);
    System.out.println(result); // 30
}
```

## 3. 리턴형과 매개변수의 조합

| 리턴값 | 매개변수 | 예시 |
|---|---|---|
| 있음 | 있음 | String substring(int start) |
| 있음 | 없음 | double random() |
| 없음 | 있음 | void println(String s) |
| 없음 | 없음 | void println() |

메소드는 직접적으로 하나의 값을 반환한다. 여러 값을 전달하려면 배열, 컬렉션 또는 사용자 정의 클래스를 활용할 수 있다.

## 4. return의 역할

### 반환값이 있는 메소드

```java
static int sum(int a, int b) {
    return a + b;
}
```

return은 계산 결과를 호출한 곳으로 돌려준다.

### void 메소드

```java
static void display() {
    System.out.println("Hello");
    return; // 생략 가능
}
```

void는 반환값이 없다는 의미다. void 메소드에서는 return;으로 실행을 종료할 수 있지만 return 10;처럼 값을 반환할 수는 없다.

## 5. static 메소드와 인스턴스 메소드

### static 메소드

객체를 생성하지 않고 클래스 이름으로 호출할 수 있다.

```java
class Calculator {
    static int add(int a, int b) {
        return a + b;
    }
}

// 호출
int result = Calculator.add(3, 4);
```

### 인스턴스 메소드

객체를 생성한 뒤 객체를 통해 호출한다.

```java
class Greeter {
    void greet() {
        System.out.println("Hello, Java");
    }
}

// 호출
Greeter g = new Greeter();
g.greet();
```

## 6. 메소드 호출 순서와 생명주기

```java
public class MethodFlow {
    static void display() {
        System.out.println("display 진입");
        System.out.println("작업 처리");
        System.out.println("display 종료");
    }

    static void process() {
        System.out.println("process 진입");
        display();
        System.out.println("process 종료");
    }

    public static void main(String[] args) {
        System.out.println("main 시작");
        process();
        System.out.println("main 종료");
    }
}
```

실행 순서:
1. main 시작
2. process 진입
3. display 진입
4. display 작업 처리
5. display 종료
6. process 종료
7. main 종료

호출된 메소드가 종료되면 호출했던 위치 다음 줄부터 실행을 이어간다.

## 7. 구구단 출력

사용자가 입력한 단을 출력한다.

```java
import java.util.Scanner;

public class Method1 {
    static void gugudan(int dan) {
        for (int i = 1; i <= 9; i++) {
            System.out.println(dan + " * " + i + " = " + dan * i);
        }
    }

    static void process() {
        Scanner scan = new Scanner(System.in);
        System.out.print("2~9 사이의 단 입력: ");
        int dan = scan.nextInt();

        if (dan < 2 || dan > 9) {
            System.out.println("잘못된 입력입니다.");
            return;
        }

        gugudan(dan);
    }

    public static void main(String[] args) {
        process();
    }
}
```

gugudan은 매개변수 dan을 받고 결과를 직접 출력하므로 리턴형은 void다.

## 8. 사칙연산 계산기

```java
static int plus(int a, int b) {
    return a + b;
}

static int minus(int a, int b) {
    return a - b;
}

static int multiply(int a, int b) {
    return a * b;
}

static String divide(int a, int b) {
    if (b == 0) {
        return "0으로 나눌 수 없습니다.";
    }
    return String.valueOf(a / (double) b);
}
```

- 덧셈, 뺄셈, 곱셈은 int를 반환한다.
- 나눗셈은 소수점 결과를 표현하기 위해 double 계산을 사용한다.
- 0으로 나누는 경우를 먼저 확인한다.

## 9. 로그인 확인

```java
static boolean isLogin(String id, String pwd) {
    final String MID = "hong";
    final String PWD = "1234";

    return id.equals(MID) && pwd.equals(PWD);
}
```

boolean은 true 또는 false를 반환한다.

문자열의 내용 비교에는 == 대신 equals()를 사용한다.

실제 서비스에서는 아이디와 비밀번호를 코드에 고정하지 않고, 비밀번호를 안전하게 관리해야 한다.

## 10. 배열 최댓값과 정렬

```java
import java.util.Arrays;

public class MethodPractice2 {
    static int max(int[] arr) {
        int m = arr[0];

        for (int i = 1; i < arr.length; i++) {
            if (m < arr[i]) {
                m = arr[i];
            }
        }

        return m;
    }

    static int[] sort(int[] arr) {
        Arrays.sort(arr);
        return arr;
    }

    public static void main(String[] args) {
        int[] arr = {10, 30, 50, 20, 40};

        System.out.println("최댓값: " + max(arr));
        System.out.println("정렬 결과: "
                + Arrays.toString(sort(arr)));
    }
}
```

출력:

```text
최댓값: 50
정렬 결과: [10, 20, 30, 40, 50]
```

- int[]는 정수 배열을 의미한다.
- 배열은 참조형이다.
- Arrays.sort()는 원본 배열을 오름차순으로 정렬한다.
- 배열이 비어 있으면 arr[0]을 사용할 수 없으므로 별도 검사가 필요하다.

## 11. 숫자 야구 게임

| 메소드 | 역할 | 리턴형 |
|---|---|---|
| rand() | 컴퓨터 숫자 3개 생성 | int[] |
| userInput() | 사용자 입력 처리 | int[] |
| hint(com, user) | 스트라이크·볼 계산 | int |
| exit(s) | 정답 여부 확인 | boolean |
| process() | 전체 게임 진행 | void |

### 컴퓨터 숫자 생성

```java
static int[] rand() {
    int[] com = new int[3];

    for (int i = 0; i < com.length; i++) {
        com[i] = (int)(Math.random() * 9) + 1;

        for (int j = 0; j < i; j++) {
            if (com[i] == com[j]) {
                i--;
                break;
            }
        }
    }

    return com;
}
```

### 스트라이크와 볼 계산

```java
static int hint(int[] com, int[] user) {
    int s = 0;
    int b = 0;

    for (int i = 0; i < com.length; i++) {
        for (int j = 0; j < user.length; j++) {
            if (com[i] == user[j]) {
                if (i == j) {
                    s++;
                } else {
                    b++;
                }
            }
        }
    }

    System.out.printf("%dS-%dB%n", s, b);
    return s;
}
```

### 정답 여부 확인

```java
static boolean exit(int s) {
    return s == 3;
}
```

주의사항:
- 사용자 입력은 중복 숫자와 0을 검사한다.
- 게임 재시작에는 재귀 호출보다 반복문을 사용하는 것이 안전하다.
- System.exit(0)은 프로그램 전체를 종료한다.

## 12. 기본형과 참조형

### 기본형

byte, short, int, long, float, double, char, boolean

### 참조형

배열, 클래스, 인터페이스 등의 타입

```java
int number = 10;
int[] numbers = {1, 2, 3};
String name = "홍길동";
```

- 기본형은 값 자체를 저장한다.
- 참조형 변수는 객체나 배열을 참조한다.
- 배열은 같은 자료형의 데이터를 여러 개 저장한다.
- 클래스는 서로 다른 종류의 데이터를 하나의 객체로 묶을 수 있다.

## 13. 메소드의 장점

1. 코드 중복을 줄인다.
2. 작성한 기능을 재사용할 수 있다.
3. 가독성이 좋아진다.
4. 유지보수가 쉬워진다.
5. 기능별 테스트가 편리하다.
6. 프로그램을 구조적으로 설계할 수 있다.

main에서 변수, 연산자, 제어문을 절대 사용하면 안 되는 것은 아니다. 다만 기능을 적절히 분리하면 전체 흐름을 이해하기 쉬워진다.

## 14. 코드 작성 시 주의사항

### sum 메소드의 매개변수 사용

잘못된 예:

```java
static int sum(int n) {
    int s = 0;
    for (int i = 1; i <= 10; i++) {
        s += i;
    }
    return s;
}
```

매개변수 n을 받지만 실제 반복 범위는 10으로 고정되어 있다.

수정 예:

```java
static int sum(int n) {
    int s = 0;

    for (int i = 1; i <= n; i++) {
        s += i;
    }

    return s;
}
```

호출:

```java
int result = sum(10); // 55
```

초기화하지 않은 변수를 인수로 전달하면 컴파일 오류가 발생할 수 있다. 예를 들어 int s = sum(s);는 잘못된 코드다.

### 알파벳 반복문

잘못된 예:

```java
for (char c = 'A'; 'A' <= 'Z'; c++) {
    System.out.print(c);
}
```

조건이 항상 참이므로 반복이 끝나지 않는다.

수정 예:

```java
for (char c = 'A'; c <= 'Z'; c++) {
    System.out.print(c + " ");
}
```

### 대문자를 소문자로 변환

```java
static char change(char c) {
    if (c >= 'A' && c <= 'Z') {
        return (char)(c + ('a' - 'A'));
    }
    return c;
}
```

### Java 파일 구성

public 최상위 클래스는 일반적으로 파일 하나에 하나씩 두며, 파일명은 public 클래스 이름과 같아야 한다.

## 15. 핵심 요약

- 매개변수: 메소드에 전달하는 입력값
- 리턴형: 메소드가 반환하는 값의 자료형
- return 값: 결과를 반환하고 메소드 종료
- void: 반환값 없음
- static: 객체 생성 없이 클래스 이름으로 호출 가능
- 배열 반환: 같은 자료형의 여러 값을 전달
- 메소드 종료 후: 호출 위치 다음 줄로 복귀
- 메소드 분리: 재사용성, 가독성, 유지보수성 향상
