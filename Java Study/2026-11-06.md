# 2. Object 클래스

## 2-1. Object 클래스의 특징

- Java의 모든 클래스가 기본적으로 상속받는 최상위 클래스
- 별도로 extends를 작성하지 않아도 Object를 상속받음
- 모든 참조형 객체를 Object 타입으로 받을 수 있음
- Object의 메서드를 모든 클래스에서 사용할 수 있음

```java
class A {
    int a;
}

class B extends A {
    int b;
}

Object o = new A();
Object o2 = new B();
Object o3 = "Hello";
```

### 주요 메서드

| 메서드 | 기능 |
|---|---|
| toString() | 객체를 문자열로 변환 |
| equals() | 객체 비교 |
| hashCode() | 해시값 반환 |
| getClass() | 객체의 클래스 정보 반환 |
| clone() | 객체 복제 |
| finalize() | 객체 소멸 관련 메서드 (Deprecated) |

※ finalize()는 최신 Java에서 사용하지 않는 것이 권장된다.

## 2-2. toString() : 객체를 문자열로 변환

### 기본 개념

객체를 출력할 때 자동으로 toString()이 호출된다.

```java
System.out.println(m1);
System.out.println(m1.toString());
```

위 두 코드는 동일한 결과를 출력한다.

### 기본 toString()

```java
return getClass().getName() + "@" +
       Integer.toHexString(hashCode());
```

기본적으로 클래스명과 해시코드 기반의 문자열을 반환한다. 흔히 주소값이라고 표현하지만 실제 메모리 주소는 아니다.

### toString() 오버라이딩

```java
class Member {
    private String name;
    private String sex;

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public String getSex() {
        return sex;
    }

    public void setSex(String sex) {
        this.sex = sex;
    }

    @Override
    public String toString() {
        return "이름:" + name + ", 성별:" + sex;
    }
}

public class Object_2 {
    public static void main(String[] args) {
        Member m1 = new Member();

        m1.setName("홍길동");
        m1.setSex("남자");

        System.out.println(m1);
        System.out.println(m1.toString());
    }
}
```

### 실행 결과

```text
이름:홍길동, 성별:남자
이름:홍길동, 성별:남자
```

### 핵심 정리
- 오버라이딩 전: Object의 기본 toString() 실행
- 오버라이딩 후: 개발자가 정의한 문자열 반환
- 객체를 출력하면 자동으로 toString() 호출

## 2-3. getClass() : 클래스 정보 확인

- 클래스 정보 확인 및 리플렉션에서 활용

# 3. 객체 비교와 HashCode

## 3-1. equals() : 객체 비교

기본적으로 Object의 equals()는 두 객체의 참조값이 같은지 비교한다.

```java
Human h1 = new Human("홍길동", "남자");
Human h2 = new Human("홍길동", "남자");
Human h3 = h1;

System.out.println(h1.equals(h2));
System.out.println(h1.equals(h3));
```

오버라이딩하지 않은 경우:

```text
false
true
```

- h1과 h2: 서로 다른 객체
- h1과 h3: 동일한 객체를 참조

## 3-2. equals() 오버라이딩

객체의 주소가 아닌 내부 데이터를 기준으로 비교할 수 있다.

```java
class Human {
    private String name;
    private String sex;

    public Human(String n, String s) {
        name = n;
        sex = s;
    }

    @Override
    public boolean equals(Object obj) {
        if (obj instanceof Human) {
            Human h = (Human) obj;

            return Objects.equals(name, h.name)
                && Objects.equals(sex, h.sex);
        }

        return false;
    }
}
```

### 사용 예제

```java
public class Object_3 {
    public static void main(String[] args) {

        Human h1 = new Human("홍길동", "남자");
        Human h2 = new Human("홍길동", "남자");
        Human h3 = h1;

        if (h1.equals(h2)) {
            System.out.println("두 객체의 데이터가 같다.");
        } else {
            System.out.println("두 객체의 데이터가 다르다.");
        }
    }
}
```

### 핵심 개념

| 비교 방법 | 비교 대상 |
|---|---|
| == | 기본형은 값, 참조형은 참조값 |
| equals() 기본형태 | 객체의 참조값 |
| equals() 오버라이딩 | 개발자가 정의한 비교 기준 |

※ String은 equals()가 이미 오버라이딩되어 있으므로 문자열의 실제 내용을 비교한다.

```java
String s1 = new String("Hello");
String s2 = new String("Hello");

System.out.println(s1 == s2);      // false
System.out.println(s1.equals(s2)); // true
```

## 3-3. hashCode() : 객체 구분을 위한 해시값

- 객체의 해시값을 정수형으로 반환
- HashSet, HashMap 등의 컬렉션에서 활용
- 기본 hashCode()는 객체별 해시값을 제공
- 오버라이딩하여 동일한 데이터의 객체가 같은 해시값을 갖도록 구현 가능

### equals()와 hashCode()의 관계

중요한 규칙:

1. equals()가 true이면 hashCode()도 반드시 같아야 한다.
2. hashCode()가 같다고 equals()도 true인 것은 아니다.
3. hashCode()는 객체의 실제 메모리 주소가 아니다.

## 3-4. equals()와 hashCode() 활용 예제

```java
import java.util.*;

class Sawon {
    private int sabun;
    private String name;

    public Sawon(int sabun, String name) {
        this.sabun = sabun;
        this.name = name;
    }

    public int getSabun() {
        return sabun;
    }

    public String getName() {
        return name;
    }

    @Override
    public boolean equals(Object obj) {
        if (obj instanceof Sawon) {
            Sawon s = (Sawon) obj;

            return sabun == s.sabun
                && Objects.equals(name, s.name);
        }

        return false;
    }

    @Override
    public int hashCode() {
        return Objects.hash(sabun, name);
    }
}

public class Object_4 {
    public static void main(String[] args) {

        Sawon s1 = new Sawon(1, "박문수");
        Sawon s2 = new Sawon(1, "박문수");

        System.out.println(s1.hashCode());
        System.out.println(s2.hashCode());

        Set<Sawon> set = new HashSet<>();

        set.add(s1);
        set.add(s2);

        for (Sawon s : set) {
            System.out.println(s.getSabun());
            System.out.println(s.getName());
        }
    }
}
```

### 실행 결과

```text
동일한 해시값
동일한 해시값

1
박문수
```

실제 해시값의 숫자는 실행 환경에 따라 달라질 수 있다.

### HashSet의 중복 제거 과정

1. hashCode()를 이용하여 해시값 확인
2. 같은 해시값을 가진 객체가 있으면 equals()로 비교
3. equals()가 true이면 중복으로 판단
4. 중복 객체는 추가하지 않음

**중요:** 해시값이 같다는 이유만으로 동일한 객체라고 판단하는 것은 아니다.

# 4. System 클래스

System 클래스는 프로그램의 입출력, 종료, 메모리 관리 요청, 시간 측정, 시스템 정보 확인 등의 기능을 제공한다.

## 4-1. 프로그램 종료 : exit()

```java
System.exit(0);
```

| 값 | 의미 |
|---|---|
| 0 | 정상 종료 |
| 0이 아닌 값 | 일반적으로 오류 또는 비정상 종료 표시 |

### break와 비교

```java
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;
    }

    System.out.println(i);
}
```

- break : 반복문 종료
- System.exit(0) : JVM 프로그램 전체 종료

## 4-2. 표준 입출력

| 명령어 | 기능 |
|---|---|
| System.in | 표준 입력 |
| System.out | 표준 출력 |
| System.out.print() | 줄바꿈 없이 출력 |
| System.out.println() | 줄바꿈하여 출력 |
| System.out.printf() | 형식 지정 출력 |

### printf() 형식

| 서식 | 의미 |
|---|---|
| %d | 정수 |
| %s | 문자열 |
| %f | 실수 |
| %c | 문자 |

## 4-3. System.in.read()

키보드로 입력된 바이트를 읽는다.

```java
public class System_2 {
    public static void main(String[] args) {

        try {
            System.out.print("문자 입력:");

            int num1 = System.in.read();

            System.out.println(num1);
        }
        catch (Exception ex) {
            ex.printStackTrace();
        }
    }
}
```

### 특징
- 입력된 문자를 바이트 단위로 읽음
- 숫자 1을 입력해도 정수 1이 아닌 문자 코드 49가 반환됨
- Enter 입력 시 줄바꿈 문자도 입력 스트림에 들어감
- 일반적인 사용자 입력에는 Scanner 또는 BufferedReader가 더 편리함

```java
int num = System.in.read();
System.out.println(num - '0');
```

위 코드는 한 자리 숫자 문자를 정수로 변환하는 간단한 방법이다.

## 4-4. 가비지 컬렉션 : gc()

```java
System.gc();
```

- JVM에 가비지 컬렉션 실행을 요청
- 사용하지 않는 객체의 메모리 회수를 유도
- 실제 실행 시점은 JVM이 결정
- 반드시 즉시 메모리가 회수되는 것은 아님

## 4-5. 실행 시간 측정 : currentTimeMillis()

```java
public class System_3 {
    public static void main(String[] args) {

        long start = System.currentTimeMillis();

        for (int i = 1; i <= 1000000; i++) {
            // 반복 작업
        }

        long end = System.currentTimeMillis();

        System.out.println("걸린 시간:" + (end - start) + "ms");
    }
}
```

- currentTimeMillis() : 1970년 1월 1일부터 현재까지의 시간을 밀리초로 반환
- end - start : 실행에 걸린 시간
- 1초 = 1000ms

| 속성 | 의미 |

| user.home | 사용자 홈 디렉터리 |
| java.version | Java 버전 |

# 5. String 클래스

## 5-1. String의 특징

- 문자열을 저장하고 처리하는 클래스
- java.lang 패키지에 포함
- 별도의 import 없이 사용 가능
- 불변(Immutable) 객체
- 문자열 관련 다양한 메서드 제공

### String 객체 생성

```java
String s1 = "Hello";
String s2 = new String("Hello");
```

두 방식 모두 String 객체를 사용한다.

- 문자열 리터럴: 문자열 풀(String Pool)을 활용
- new String(): 새로운 String 객체를 생성

### String의 불변성

```java
String s = "Hello";

s = s + " Java";
```

기존 "Hello" 객체의 내용이 변경되는 것이 아니다.

새로운 문자열 객체가 생성되고 변수 s가 새로운 객체를 참조하게 된다.

### String과 Call By Value

Java는 항상 Call By Value 방식으로 매개변수를 전달한다.

참조형 객체를 전달할 때도 참조값의 복사본이 전달된다.

따라서 메서드 내부에서 객체의 상태를 변경하면 같은 객체에 반영될 수 있지만, 매개변수에 새로운 객체를 대입해도 원래 변수의 참조는 변경되지 않는다.

## 5-2. StringBuffer / StringBuilder

문자열을 반복적으로 결합하거나 수정할 때 사용한다.

| 구분 | String | StringBuffer | StringBuilder |
|---|---|---|---|
| 변경 | 불가능 | 가능 | 가능 |
| 문자열 수정 | 새로운 객체 생성 | 기존 객체 수정 | 기존 객체 수정 |
| 동기화 | 해당 없음 | 지원 | 미지원 |
| 특징 | 불변 문자열 | 멀티스레드 환경 고려 | 일반적인 문자열 조작에 유리 |

### 예제

```java
StringBuilder sb = new StringBuilder();

sb.append("Hello");
sb.append(" Java");

System.out.println(sb);
```

실행 결과:

```text
Hello Java
```

# 6. 문자열 주요 메서드

## 6-1. 문자열 길이 : length()

```java
String s = "Hello Java";

System.out.println(s.length());
```

결과: 10

## 6-2. 공백 제거 : trim()

```java
String s = "  Hello Java  ";

System.out.println(s.trim());
```

결과:

```text
Hello Java
```

※ trim()은 문자열 양쪽의 공백 문자를 제거한다. 모든 Unicode 공백을 처리하려면 strip()도 알아두면 좋다.

## 6-3. 문자열 자르기 : substring()

```java
String s = "Hello Java";

System.out.println(s.substring(6));
System.out.println(s.substring(0, 5));
```

결과:

```text
Java
Hello
```

| 메서드 | 의미 |
|---|---|
| substring(start) | start부터 마지막까지 |
| substring(start, end) | start부터 end 직전까지 |

※ 인덱스는 0부터 시작하며 end는 포함하지 않는다.

## 6-4. 문자열 위치 찾기 : indexOf()

```java
String s = "Hello Java";

System.out.println(s.indexOf("Java"));
System.out.println(s.lastIndexOf("a"));
```

| 메서드 | 기능 |
|---|---|
| indexOf() | 앞에서부터 검색 |
| lastIndexOf() | 뒤에서부터 검색 |

찾는 문자열이 없으면 -1을 반환한다.

## 6-5. 문자열 비교 : equals()

```java
String msg1 = "Hello Java";
String msg2 = "HELLO JAVA";

System.out.println(msg1.equals(msg2));
System.out.println(msg1.equalsIgnoreCase(msg2));
```

| 메서드 | 기능 |
|---|---|
| equals() | 대소문자를 구분하여 비교 |
| equalsIgnoreCase() | 대소문자를 구분하지 않고 비교 |

## 6-6. 문자열 포함 여부 : contains()

```java
String msg = "Hello Java";

if (msg.contains("Java")) {
```

# 7. 문자열 분리와 정규식

## 7-1. split() : 문자열 분리

문자열을 특정 구분자로 분리하여 배열로 반환한다.

```java
String data = "알감자, 양파, 대파, 청양고추, 마늘";

String[] datas = data.split(",");

for (String s : datas) {
    System.out.println(s.trim());
}
```

결과:

```text
알감자
양파
대파
청양고추
마늘
```

### 특징
- 반환형은 String[]
- 구분자는 정규식으로 지정
- 배열 인덱스를 통해 각각의 데이터 접근 가능

## 7-2. StringTokenizer

문자열을 구분자 기준으로 분리하는 클래스다.

```java
import java.util.StringTokenizer;

String data = "알감자, 양파, 대파, 청양고추, 마늘";

StringTokenizer st = new StringTokenizer(data, ",");

System.out.println("분리된 재료:" + st.countTokens());

while (st.hasMoreTokens()) {
    System.out.println(st.nextToken().trim());
}
```

### 주요 메서드

| 메서드 | 기능 |
|---|---|
| countTokens() | 남아 있는 토큰 개수 |
| hasMoreTokens() | 읽을 토큰이 남아 있는지 확인 |
| nextToken() | 다음 토큰 반환 |

### split()과 StringTokenizer 비교

| 구분 | split() | StringTokenizer |
|---|---|---|
| 패키지 | java.lang.String | java.util |
| 반환형 | String[] | StringTokenizer |
| 분리 결과 | 배열 | 토큰 |
| 정규식 | 사용 | 사용하지 않음 |
| 빈 문자열 처리 | 빈 문자열 요소가 생길 수 있음 | 빈 토큰은 기본적으로 무시 |

## 7-3. 정규식(Regular Expression)

문자열에서 특정 패턴을 찾거나 변경할 때 사용한다.

### 주요 정규식 기호

| 기호 | 의미 |
|---|---|
| ^ | 문자열의 시작 또는 문자 집합에서 제외 |
| $ | 문자열의 끝 |
| \| | OR 선택 |
| ? | 0개 또는 1개 |
| + | 1개 이상 |
| * | 0개 이상 |
| . | 줄바꿈을 제외한 임의의 한 문자 |
| [0-9] | 숫자 |
| [A-Za-z] | 영문자 |
| [가-힣] | 한글 음절 |

### 정규식을 활용한 문자열 변경

```java
String temp = "3상승";

String state = temp.replaceAll("[^가-힣]", "");
int id = Integer.parseInt(temp.replaceAll("[^0-9]", ""));

System.out.println(state);
System.out.println(id);
```

결과:

```text
상승
3
```

### 정규식을 이용한 특정 문자 제거

```java
String data = "abc123가나다";

System.out.println(data.replaceAll("[^0-9]", ""));
```

결과:

```text
123
```

## 7-4. split()에서 특수문자 구분하기

특수문자 중 일부는 정규식에서 특별한 의미를 갖는다.

예를 들어 |는 OR 연산자로 사용되므로 일반 문자로 분리하려면 이스케이프 처리가 필요하다.

```java
String color = "red|green|blue|black|white";

String[] colors = color.split("\\|");

for (String c : colors) {
    System.out.println(c);
}
```

또는 다음과 같이 작성할 수 있다.

```java
String[] colors = color.split(Pattern.quote("|"));
```

StringTokenizer에서는 일반 구분자로 지정할 수 있다.

```java
StringTokenizer st = new StringTokenizer(color, "|");

while (st.hasMoreTokens()) {
    System.out.println(st.nextToken());
}
```

# 8. Object와 제네릭을 활용한 Swing 이벤트

## 8-1. Swing의 JComboBox

JComboBox는 여러 항목 중 하나를 선택할 수 있는 GUI 컴포넌트다.

```java
import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

public class Object_1 extends JFrame implements ItemListener {

    JComboBox<String> box = new JComboBox<>();
    JLabel la = new JLabel();

    public Object_1() {

        box.addItem("홍길동");
        box.addItem("심청이");
        box.addItem("박문수");
        box.addItem("이순신");
        box.addItem("김두한");

        add("North", box);
        add("Center", la);

        setSize(300, 250);
        setVisible(true);
        setDefaultCloseOperation(EXIT_ON_CLOSE);

        box.addItemListener(this);
    }

    @Override
    public void itemStateChanged(ItemEvent e) {

        if (e.getSource() == box) {

            String name = box.getSelectedItem().toString();

            la.setText(name);
        }
    }

    public static void main(String[] args) {
        new Object_1();
    }
}
```

## 9-8. 크롤링 결과 출력

```java
for (MusicVO vo : musics) {
```

### 주의사항
- 배열의 모든 요소가 초기화된 것은 아니다.
- musics 배열 크기가 50이므로 실제 수집 데이터가 50개보다 적으면 null이 남을 수 있다.

따라서 다음과 같이 검사하는 것이 안전하다.

```java
for (MusicVO vo : musics) {

    if (vo != null) {
        System.out.println(
            vo.getMno() + "." + vo.getTitle()
        );
    }
}
```

## 10-4. 이번 수업에서 반드시 이해할 내용

- Object는 모든 Java 클래스의 최상위 클래스다.
- 오버라이딩은 부모 클래스의 메서드를 자식 클래스에서 재정의하는 것이다.
- toString()은 객체를 문자열로 출력할 때 호출된다.
- equals()는 객체의 비교 기준을 재정의할 수 있다.
- hashCode()와 equals()는 함께 오버라이딩하는 것이 원칙이다.
- String은 불변 객체다.
- String의 문자열 비교는 ==가 아닌 equals()를 사용한다.
- split()과 StringTokenizer는 문자열을 분리하는 기능이다.
- 정규식은 문자열 검색과 변경에 활용한다.
- Object 타입은 다양한 객체를 받을 수 있지만 필요한 경우 형변환이 필요하다.
- 제네릭은 데이터 타입을 명확하게 지정하여 안정성을 높인다.
- 크롤링 프로젝트는 HTML 수집 → 데이터 추출 → 객체 저장 → 출력 순서로 진행된다.
